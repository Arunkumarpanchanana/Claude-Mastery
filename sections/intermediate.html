Make your first Anthropic API call and understand the full request/response cycle
Master system prompts, multi-turn conversations, temperature and streaming

Use tool calling and function use in multi-turn agent conversations
Build and connect MCP servers with tools, resources, and prompts
Use Claude Code end-to-end: install, explore, plan, code, commit, and review
