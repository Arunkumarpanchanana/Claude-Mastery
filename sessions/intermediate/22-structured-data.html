Structured Data & JSON Outputs

Get machine-readable JSON from Claude every time — with prompt patterns, Pydantic validation, and tool-based structured output.

35 min Intermediate Code Lab 5 Quiz Questions

Why Structured Output Matters

Free-text responses are great for humans, but applications need data they can parse, validate, and act on. Getting Claude to reliably return JSON unlocks use cases like data pipelines, form filling, entity extraction, and API integrations.

Prompting for JSON

The simplest approach: explicitly ask for JSON in the prompt and describe the schema:

import anthropic
import json

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=512,
    temperature=0,  # Always use low temperature for structured output
    messages=[{
        "role": "user",
        "content": """Extract the contact information from this text and return ONLY valid JSON.
No explanation, no markdown, just the JSON object.

Schema:
{
  "name": string,
  "email": string | null,
  "phone": string | null,
  "company": string | null
}

Text: "Hi, I'm Sarah Chen from Acme Corp. Reach me at sarah@acme.com or 415-555-0123."
"""
    }]
)

# Parse the JSON response
data = json.loads(response.content[0].text)
print(data["name"])   # Sarah Chen
print(data["email"])  # sarah@acme.com

The Prefill Trick for Reliable JSON

Prefill the assistant's response with { to force Claude to start generating JSON immediately (no preamble):

response = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=512,
    temperature=0,
    messages=[
        {
            "role": "user",
            "content": "Extract: name, sentiment (positive/negative/neutral), score (0-1) from: 'The product is amazing! Highly recommend it.'"
        },
        {
            "role": "assistant",
            "content": "{"  # Prefill forces JSON-first output
        }
    ]
)

# The response continues from the prefill
full_json = "{" + response.content[0].text
data = json.loads(full_json)

Pydantic for Validation

Pydantic models add type safety and validation on top of JSON parsing:

from pydantic import BaseModel, EmailStr, field_validator
from typing import Optional
import json

class ContactInfo(BaseModel):
    name: str
    email: Optional[str] = None
    phone: Optional[str] = None
    company: Optional[str] = None

    @field_validator("phone")
    @classmethod
    def clean_phone(cls, v):
        if v:
            return "".join(filter(str.isdigit, v))
        return v

# Parse and validate
raw = response.content[0].text
contact = ContactInfo(**json.loads(raw))
print(contact.name)   # Validated string
print(contact.model_dump())  # Dict representation

Tools for Guaranteed Structure

The most reliable approach is using Claude's tool-use feature with a schema — Claude is forced to return the exact shape you define:

tools = [{
    "name": "extract_contact",
    "description": "Extract contact information from text",
    "input_schema": {
        "type": "object",
        "properties": {
            "name": {"type": "string", "description": "Full name"},
            "email": {"type": "string", "description": "Email address"},
            "phone": {"type": "string", "description": "Phone number"},
            "company": {"type": "string", "description": "Company name"}
        },
        "required": ["name"]
    }
}]

response = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=512,
    tools=tools,
    tool_choice={"type": "tool", "name": "extract_contact"},  # Force this tool
    messages=[{"role": "user", "content": "Hi, I'm Bob from TechCo. bob@techco.io"}]
)

# Tool result is always structured correctly
tool_block = response.content[0]
print(tool_block.input)  # {"name": "Bob", "email": "bob@techco.io", "company": "TechCo"}
Best approach by reliability: Tool use with schema > Prefill trick > Explicit JSON prompt. Use tools when you need guaranteed structure. Use prompt-based JSON when you want a simpler setup.

Lab: Extract Structured Data from Unstructured Text

Build a pipeline that extracts product information from unstructured descriptions and validates it with Pydantic.

Open in Colab 
"""
structured_extraction.py — Extract product data from unstructured text
pip install anthropic pydantic
"""
import anthropic
import json
from pydantic import BaseModel, field_validator
from typing import Optional

client = anthropic.Anthropic()

# --- Define the schema ---
class ProductInfo(BaseModel):
    name: str
    price_usd: Optional[float] = None
    category: str
    in_stock: bool
    features: list[str]
    rating: Optional[float] = None

    @field_validator("rating")
    @classmethod
    def check_rating(cls, v):
        if v is not None and not (0.0 <= v <= 5.0):
            raise ValueError("Rating must be 0-5")
        return v


EXTRACTION_TOOL = [{
    "name": "save_product",
    "description": "Save extracted product information",
    "input_schema": {
        "type": "object",
        "properties": {
            "name": {"type": "string"},
            "price_usd": {"type": "number"},
            "category": {"type": "string"},
            "in_stock": {"type": "boolean"},
            "features": {"type": "array", "items": {"type": "string"}},
            "rating": {"type": "number"}
        },
        "required": ["name", "category", "in_stock", "features"]
    }
}]


def extract_product(description: str) -> ProductInfo:
    """Extract structured product data from a free-text description."""
    response = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=512,
        temperature=0,
        tools=EXTRACTION_TOOL,
        tool_choice={"type": "tool", "name": "save_product"},
        messages=[{
            "role": "user",
            "content": f"Extract product information from this description:\n\n{description}"
        }]
    )

    tool_input = response.content[0].input
    return ProductInfo(**tool_input)


# --- Test with sample descriptions ---
samples = [
    "The EcoBlend Pro Blender is on sale for $89.99. It's a kitchen appliance with 10-speed settings, a 64oz BPA-free jar, and dishwasher-safe parts. Currently in stock. Customer rating: 4.7/5.",
    "SOLD OUT: Vintage Oak Writing Desk (furniture). Features: solid oak construction, 3 drawers, cable management holes. No price listed.",
    "Python Mastery Course — Online Education. Price: $199. Includes 42 hours of video, downloadable resources, certificate of completion. Available now. Rated 4.9 stars by 1,203 students.",
]

for i, desc in enumerate(samples, 1):
    print(f"\n--- Product {i} ---")
    print(f"Input: {desc[:80]}...")
    product = extract_product(desc)
    print(f"Extracted: {product.model_dump_json(indent=2)}")
    print(f"In stock : {product.in_stock}")
    print(f"Features : {len(product.features)} features found")
