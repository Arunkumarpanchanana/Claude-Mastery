Claude Code — Install & First Prompt

Claude Code is an agentic coding assistant that lives in your terminal — it reads your codebase, writes code, runs tests, and commits changes.

40 min Intermediate Code Lab 5 Quiz Questions

What Is Claude Code?

Claude Code is a CLI-based agentic coding assistant. Unlike chat-based coding tools, Claude Code:

  • Runs directly in your terminal alongside your code
  • Reads and modifies actual files in your project
  • Runs shell commands, tests, and builds
  • Uses git — creates commits, reads history, understands diffs
  • Operates autonomously across multi-step tasks

Installation

# Install via npm (recommended)
npm install -g @anthropic-ai/claude-code

# Or via Homebrew (macOS)
brew install claude-code

# Verify installation
claude --version

Authentication

# First-time setup
claude

# Authenticate with:
# Option 1: Anthropic account (api.anthropic.com)
# Option 2: Claude.ai Pro/Team account
# Option 3: Set ANTHROPIC_API_KEY environment variable

export ANTHROPIC_API_KEY="sk-ant-..."

Project Setup

Navigate to your project directory and launch Claude Code:

cd /path/to/your-project
claude

# Claude Code reads your project structure automatically:
# - Directory tree
# - README.md and CLAUDE.md if present
# - git history
# - File contents as needed

How Claude Code Reads Context

Claude Code doesn't read every file upfront — it reads strategically:

  1. Starts with the directory tree to understand structure
  2. Reads CLAUDE.md for project-specific instructions
  3. Reads README.md for project overview
  4. Reads specific files as needed based on your request
  5. Uses git log to understand recent changes

Your First Prompt

Good first prompts are specific and include the desired outcome:

# In the Claude Code terminal prompt:

# Exploration
> What does this codebase do? Summarize the architecture.

# Creating files
> Create a Python script called hello.py that prints 'Hello, World!' and run it.

# Bug fixing
> The function in utils.py line 42 raises a KeyError when the input dict is empty. Fix it and add a test.

# Feature addition
> Add a /health endpoint to the FastAPI app in main.py that returns {"status": "ok", "version": "1.0"}

Interactive vs Non-Interactive Mode

# Interactive (default) — opens a REPL session
claude

# Non-interactive — run a single task and exit
claude "Create a Python script that downloads the top 10 HN stories"

# Print mode — output to stdout (useful in scripts)
claude --print "Explain this error: NameError: name 'x' is not defined"

# With a specific file as context
claude --file app.py "Add docstrings to all functions in this file"
Keyboard shortcuts in Claude Code:
Ctrl+C — interrupt current operation
Esc — cancel pending tool use
/help — show available slash commands
/clear — clear context and start fresh
/quit — exit Claude Code

Complete these steps in order. By the end you'll have Claude Code installed, authenticated, and have run a real coding task.

# ── STEP 4: Run these prompts in sequence ─────────────────────────────────────
# Prompt 1 — Create a script
> Create a Python script called calculator.py with functions for add, subtract, multiply, and divide. Include type hints and docstrings. Handle division by zero.

# Prompt 2 — Add tests
> Create a pytest test file tests/test_calculator.py that tests all 4 functions including the edge cases.

# Prompt 3 — Run the tests
> Run the tests and show me the output.

# Prompt 4 — Check git status
> Show me what files changed and commit everything with a descriptive message.

# Prompt 5 — Add a feature
> Add a 'power' function to calculator.py and corresponding tests.

What to observe

  • Claude Code reads the directory structure before responding
  • It creates and modifies real files on disk
  • It runs shell commands (pytest) and shows you the output
  • It generates appropriate commit messages
  • It asks for permission before destructive operations

Expected calculator.py output from Claude Code

"""
Calculator module with basic arithmetic operations.
"""

def add(a: float, b: float) -> float:
    """Return the sum of a and b."""
    return a + b

def subtract(a: float, b: float) -> float:
    """Return the difference of a and b."""
    return a - b

def multiply(a: float, b: float) -> float:
    """Return the product of a and b."""
    return a * b

def divide(a: float, b: float) -> float:
    """Return the quotient of a divided by b.

    Raises:
        ZeroDivisionError: If b is zero.
    """
    if b == 0:
        raise ZeroDivisionError("Cannot divide by zero")
    return a / b
