Claude Cowork — Setup, Plugins & Teams

Bring Claude into your team's actual workflow — with integrations for Slack, Microsoft 365, Google Workspace, Jira, and any tool you use daily.

What Is Claude Cowork?

Claude Cowork (also called Claude for Work, or accessed via Claude.ai with a Team or Enterprise plan) is Anthropic's collaboration layer for Claude. It extends Claude beyond individual chat sessions into team workflows with:

  • Projects — shared context, files, and instructions for a team or use case
  • Global instructions — organization-wide behavior rules that apply to all sessions
  • Integrations (plugins) — connect Claude to external services
  • Shared prompts — reusable prompt templates teams can save and use
  • Skills — Claude Code plugins that add specialized workflows

Global Instructions

Global instructions are organization-level system prompt additions that apply to every Claude session across your team. Set them in Settings → Instructions.

Examples of useful global instructions:

"""
Always format code examples with language tags.
When referencing company products, use full product names (not abbreviations).
Do not include proprietary customer data in responses.
If asked about competitors, provide neutral factual information only.
All generated content should be suitable for a professional workplace.
"""
Priority: Global instructions apply team-wide and can be overridden at the Project or individual session level. This creates a layered instruction hierarchy: Organization → Project → Session.

Projects in Cowork

Projects are shared workspaces with persistent context. Each project has:

  • Project instructions — specialized behavior for this project
  • Shared files — documents Claude can reference in the project
  • Conversation history — all team members' chats in this project
  • Connected integrations — project-specific tool connections

Example projects: "Engineering Q&A", "Legal Document Review", "Marketing Copy", "Customer Support Playbook".

Key Available Integrations

  • Google Workspace — read Gmail, Docs, Drive; create calendar events
  • Microsoft 365 — read Outlook, Teams, SharePoint, OneDrive
  • Slack — read channels, search messages, post updates
  • GitHub — read repos, issues, PRs; review code
  • Jira — read/create tickets, update status
  • Confluence — read/write knowledge base articles
  • Salesforce — read CRM data, update records

Claude in Chrome

The Claude browser extension brings Claude directly into any web page:

  • Summarize any page or selected text
  • Ask questions about what you're reading
  • Fill in forms with AI-generated content
  • Extract data from web pages
  • Works on Gmail, Salesforce, HubSpot, any web app

Claude for Microsoft 365

Enterprise customers can deploy Claude as a Microsoft 365 Copilot alternative:

  • Claude inside Outlook for email drafting and summarization
  • Claude in Word for document creation and review
  • Claude in Teams for meeting summaries and follow-ups
  • Governed by your organization's data policies

Sharing With Your Team

Best practices for team rollout:

  1. Set global instructions that reflect your organization's standards
  2. Create projects for each team or use case
  3. Build a library of shared prompt templates for common tasks
  4. Document which integrations are approved by IT/security
  5. Train team members on prompt engineering basics (Sessions 22-24)

Lab: Set Up Claude Cowork for a Team

Walk through setting up a team workspace with global instructions, a project, and your first integration.

Claude for Teams

Step 1 — Upgrade to a Team Plan

Go to claude.ai → Settings → Plans → Team. Team plan includes 5+ seats, shared projects, and integration support.

Step 2 — Set Global Instructions

# Navigate to: Settings → Instructions (Admin only)
# Add your global instructions:

"""
You are assisting employees of Acme Corp, a B2B software company.

Communication standards:
- Be direct and professional. Skip filler phrases like "Certainly!" or "Great question!"
- Format code with proper language tags
- When uncertain, say so and suggest how to verify

Data handling:
- Do not reference specific customer names, contract values, or PII in responses
- If asked to process sensitive data, remind users to use approved internal tools

Tone: Professional but approachable. We value clarity over formality.
"""

Step 3 — Create Your First Project

# Claude.ai → Projects → New Project
# Name: "Engineering Team"
# Add project instructions:

"""
Project: Engineering Team Assistant

Context: Our stack is Python/FastAPI backend, React frontend, PostgreSQL, AWS.

For code questions:
- Prioritize correctness and security over cleverness
- Include error handling in all code examples
- Follow PEP 8 for Python, Prettier defaults for TypeScript/React

For architecture discussions:
- Reference our existing patterns when possible
- Flag any changes that would affect our SLA (99.9% uptime)
"""

# Upload relevant files:
# - architecture-overview.pdf
# - coding-standards.md
# - api-reference.md

Step 4 — Connect an Integration

# In the project, click "Integrations" or the + icon
# Select: GitHub (or another integration your team uses)
# Authenticate with OAuth

# Test it by asking:
# "What are the open pull requests in our main repository?"
# "Summarize the last 5 closed issues labeled 'bug'"

Step 5 — Create a Shared Prompt Template

# Useful shared prompts to create for your engineering team:

# 1. PR Review Template
"""
Review this pull request. Check for:
- Correctness: Any logic bugs or missing edge cases?
- Security: Any vulnerabilities (OWASP Top 10 relevant issues)?
- Performance: Any N+1 queries, missing indexes, or obvious bottlenecks?
- Test coverage: Are new paths covered?
- Documentation: Are public APIs documented?

For each issue: [SEVERITY: Critical/High/Medium/Low] [LINE: if applicable]
[ISSUE] [SUGGESTED FIX]
"""

# 2. Incident Summary Template
"""
Write a post-incident summary in this format:
INCIDENT: [one-line description]
IMPACT: [who was affected, for how long]
ROOT CAUSE: [technical explanation, 2-3 sentences]
TIMELINE: [key events with timestamps]
RESOLUTION: [what fixed it]
ACTION ITEMS: [numbered list of follow-ups with owners]
"""

Step 6 — Invite Team Members

Settings → Team → Invite Members. Add team email addresses. They'll receive an invitation to join your workspace with access to shared projects and global instructions.

Review: What You've Set Up

  • Global instructions enforcing organization standards
  • Engineering project with stack-specific context
  • GitHub integration for repo awareness
  • Shared prompt templates for common tasks
  • Team members invited with shared context
