Introduction to MCP

The Model Context Protocol is the USB standard for AI integrations — write a server once, connect to any compatible AI client.

40 min Intermediate Code Lab 5 Quiz Questions

What Is the Model Context Protocol?

MCP (Model Context Protocol) is an open standard developed by Anthropic that defines how AI models communicate with external tools and data sources. Instead of building custom integrations for each AI client, you build one MCP server and it works with any compliant client.

Think of it like USB: before USB, every device needed a different cable and driver. MCP creates a standard interface so your tools, databases, and services can plug into Claude (and other AI systems) without custom wiring for each one.

MCP Architecture

MCP uses a client-server architecture:

  • MCP Host — the application that wants AI capabilities (Claude Desktop, Claude Code, VS Code, custom apps)
  • MCP Client — built into the host; manages connections to servers
  • MCP Server — your code that exposes tools, resources, and prompts
Communication: MCP servers communicate over stdio (for local processes) or HTTP+SSE (for remote servers). The protocol is JSON-RPC 2.0.

MCP Clients

  • Claude Desktop — Anthropic's native app; plug in any MCP server in settings
  • Claude Code — CLI agent; reads MCP config from project settings
  • Claude.ai — web app with MCP connector support (Integrations)
  • Third-party — VS Code (Copilot), Cursor, Zed, and many others implement MCP

The Three MCP Primitives

  • Tools — functions Claude can call (like API tool use, but served by MCP)
  • Resources — data sources Claude can read (files, database records, API responses)
  • Prompts — pre-built prompt templates users can invoke by name

Why MCP Matters

Before MCP, every team building an AI integration had to:

  1. Learn each AI API's tool format
  2. Build custom glue code for each client
  3. Re-implement the same logic when switching models

With MCP, you build your server once. It works with Claude Desktop, Claude Code, and any other MCP-compatible client without code changes. The ecosystem of pre-built MCP servers (for GitHub, Postgres, Slack, web browsing, etc.) means you can give Claude powerful capabilities in minutes.

Lab: Connect the Filesystem MCP Server to Claude Desktop

In this lab, you'll install an existing MCP server (the official Anthropic filesystem server) and connect it to Claude Desktop — no code writing required.

MCP Documentation

Step 1 — Prerequisites

# Install Node.js if not already installed
# macOS: brew install node
# Windows: download from nodejs.org

# Verify installation
node --version   # Should be 18+
npx --version

Step 2 — Install Claude Desktop

Download from claude.ai/download and sign in with your Anthropic account.

Step 3 — Configure the Filesystem MCP Server

Open Claude Desktop settings, go to Developer tab, and edit the config file:

# Location of config file:
# macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
# Windows: %APPDATA%\Claude\claude_desktop_config.json

# Add this to the config:
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/YOUR_USERNAME/Documents"
      ]
    }
  }
}

Step 4 — Restart Claude Desktop

After saving the config, restart Claude Desktop. You should see a tools icon (hammer) in the chat input area indicating MCP servers are connected.

Step 5 — Test It

# Ask Claude Desktop:
"List the files in my Documents folder"
"Read the file called notes.txt"
"Create a new file called test.txt with the content 'Hello from Claude!'"

Understanding What Just Happened

The filesystem MCP server exposed tools like list_directory, read_file, and write_file. Claude Desktop discovered these tools via the MCP protocol, and Claude can now call them when needed — without you writing any API integration code.

Explore More Pre-Built Servers
