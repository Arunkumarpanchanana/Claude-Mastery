Prompt Evaluation & Eval Workflows

Stop guessing whether your prompts are good — build a test harness that measures quality automatically and catches regressions before they ship.

Why Evals Matter

Without evals, prompt changes are a black box. You think you improved the prompt — but did you? Evals give you:

  • Measurable baselines — what's the current accuracy before changes?
  • Regression detection — did a model update break something?
  • A/B comparison — which of two prompts is objectively better?
  • Confidence to ship — proof that your change improved things

Building a Test Dataset

A test dataset is a set of (input, expected_output) pairs that cover your task's range:

TEST_CASES = [
    {
        "input": "The quick brown fox jumps over the lazy dog.",
        "expected_category": "sentence",
        "notes": "Standard pangram"
    },
    {
        "input": "2+2",
        "expected_category": "math",
        "notes": "Simple arithmetic"
    },
    {
        "input": "def hello(): print('hi')",
        "expected_category": "code",
        "notes": "Python snippet"
    },
]

Dataset tips:

  • Include 20-100 cases minimum for meaningful statistics
  • Include hard cases and edge cases, not just easy ones
  • Include cases where you know the model tends to fail
  • Label the expected output as precisely as possible

Code-Based Grading

The simplest eval: write a Python function that checks the output programmatically:

def grade_exact_match(response: str, expected: str) -> bool:
    return response.strip().lower() == expected.strip().lower()

def grade_contains(response: str, expected: str) -> bool:
    return expected.lower() in response.lower()

def grade_json_schema(response: str, required_keys: list) -> bool:
    import json
    try:
        data = json.loads(response)
        return all(k in data for k in required_keys)
    except json.JSONDecodeError:
        return False

Model-Based Grading (LLM-as-Judge)

For subjective tasks (quality, helpfulness, tone), use Claude itself as the evaluator:

def grade_with_llm(prompt: str, response: str, criteria: str) -> dict:
    """Use Claude to grade a response on a given criteria."""
    grader_prompt = f"""<criteria>
{criteria}
</criteria>

<prompt>
{prompt}
</prompt>

<response>
{response}
</response>

Grade the response on the criteria above.
Return JSON: {{"score": 1-5, "reasoning": "...", "pass": true/false}}
"""
    result = client.messages.create(
        model="claude-haiku-4-5",  # Cheap model for grading
        max_tokens=256,
        temperature=0,
        messages=[{"role": "user", "content": grader_prompt}]
    )
    import json
    return json.loads(result.content[0].text)

Eval Metrics

  • Accuracy — % of test cases that passed
  • Pass@k — does at least one of k tries pass?
  • Average score — mean score from LLM grader (1-5)
  • Latency — P50 / P95 response time
  • Cost per case — average tokens × price

The Eval Workflow

  1. Build dataset from real user queries or synthetic examples
  2. Run dataset through current prompt (baseline)
  3. Make a prompt change
  4. Run dataset through new prompt
  5. Compare accuracy / score — ship if better, iterate if not
  6. Add any new failure cases to the dataset

Lab: Build an Eval Harness for a Summarization Prompt

Build a complete eval pipeline with code-based and LLM-based grading.

Open in Colab 
"""
eval_harness.py — Evaluate a summarization prompt
pip install anthropic
"""
import anthropic
import json
import time
from dataclasses import dataclass

client = anthropic.Anthropic()

# --- Test dataset ---
TEST_CASES = [
    {
        "id": "tc1",
        "text": "Python was created by Guido van Rossum and first released in 1991. It emphasizes code readability with its notable use of significant indentation. Python is dynamically typed and garbage-collected. It supports multiple programming paradigms, including structured, object-oriented and functional programming.",
        "required_keywords": ["python", "1991", "readability"],
        "max_words": 40
    },
    {
        "id": "tc2",
        "text": "The Apollo 11 mission was the first crewed lunar landing mission. Launched on July 16, 1969, it carried commander Neil Armstrong, command module pilot Michael Collins, and lunar module pilot Edwin Aldrin. On July 20, Armstrong and Aldrin became the first humans to walk on the Moon.",
        "required_keywords": ["apollo 11", "1969", "moon"],
        "max_words": 40
    },
    {
        "id": "tc3",
        "text": "Machine learning is a method of data analysis that automates analytical model building. Based on the idea that systems can learn from data, identify patterns and make decisions with minimal human intervention, machine learning is a branch of artificial intelligence.",
        "required_keywords": ["machine learning", "data", "patterns"],
        "max_words": 35
    },
]

SUMMARIZATION_PROMPT = """Summarize the following text in 1-2 sentences.
Be concise. Include the most important facts.

<text>
{text}
</text>"""


@dataclass
class EvalResult:
    test_id: str
    response: str
    word_count: int
    keywords_found: list[str]
    keywords_missing: list[str]
    llm_score: int
    llm_reasoning: str
    passed: bool
    latency_ms: float


def run_summarization(text: str) -> tuple[str, float]:
    """Run the summarization prompt and return (text, latency_ms)."""
    start = time.time()
    response = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=128,
        temperature=0,
        messages=[{
            "role": "user",
            "content": SUMMARIZATION_PROMPT.format(text=text)
        }]
    )
    latency = (time.time() - start) * 1000
    return response.content[0].text.strip(), latency


def grade_response(test_case: dict, response: str) -> dict:
    """Code-based grading."""
    word_count = len(response.split())
    keywords_found = [k for k in test_case["required_keywords"]
                      if k.lower() in response.lower()]
    keywords_missing = [k for k in test_case["required_keywords"]
                        if k.lower() not in response.lower()]
    return {
        "word_count": word_count,
        "keywords_found": keywords_found,
        "keywords_missing": keywords_missing,
        "within_limit": word_count <= test_case["max_words"]
    }


def grade_with_llm(original_text: str, summary: str) -> dict:
    """LLM-as-judge grading."""
    judge_prompt = f"""Rate this summary of a passage on a scale of 1-5.

Original: {original_text[:300]}

Summary: {summary}

Criteria: accuracy (is the summary factually correct?), completeness (key facts included?), conciseness (not verbose?).

Return JSON only: {{"score": 1-5, "reasoning": "one sentence"}}"""

    result = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=100,
        temperature=0,
        messages=[{"role": "user", "content": judge_prompt}]
    )
    return json.loads(result.content[0].text.strip())


def run_eval() -> list[EvalResult]:
    """Run the full eval suite."""
    results = []
    for tc in TEST_CASES:
        print(f"Running {tc['id']}...")
        response, latency = run_summarization(tc["text"])
        code_grade = grade_response(tc, response)
        llm_grade = grade_with_llm(tc["text"], response)

        passed = (
            code_grade["within_limit"] and
            len(code_grade["keywords_missing"]) == 0 and
            llm_grade["score"] >= 4
        )

        results.append(EvalResult(
            test_id=tc["id"],
            response=response,
            word_count=code_grade["word_count"],
            keywords_found=code_grade["keywords_found"],
            keywords_missing=code_grade["keywords_missing"],
            llm_score=llm_grade["score"],
            llm_reasoning=llm_grade["reasoning"],
            passed=passed,
            latency_ms=latency
        ))
    return results


def print_report(results: list[EvalResult]) -> None:
    """Print eval report."""
    passed = sum(1 for r in results if r.passed)
    print(f"\n{'='*60}")
    print(f"EVAL RESULTS: {passed}/{len(results)} passed ({passed/len(results)*100:.0f}%)")
    print(f"Avg latency : {sum(r.latency_ms for r in results)/len(results):.0f}ms")
    print(f"Avg LLM score: {sum(r.llm_score for r in results)/len(results):.1f}/5")
    print()
    for r in results:
        status = "PASS" if r.passed else "FAIL"
        print(f"[{status}] {r.test_id}")
        print(f"  Summary   : {r.response[:80]}...")
        print(f"  Words     : {r.word_count}")
        print(f"  Keywords  : found={r.keywords_found}, missing={r.keywords_missing}")
        print(f"  LLM score : {r.llm_score}/5 — {r.llm_reasoning}")
        print(f"  Latency   : {r.latency_ms:.0f}ms\n")


if __name__ == "__main__":
    results = run_eval()
    print_report(results)
