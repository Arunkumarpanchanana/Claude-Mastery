Temperature, Streaming & Output Control

Dial creativity with temperature, stream tokens in real time, and use stop sequences to control exactly where Claude stops.

Temperature — Controlling Randomness

Temperature is a float between 0.0 and 1.0 that controls how deterministic Claude's output is:

ValueBehaviorBest for
0.0Nearly deterministic — same prompt = same outputData extraction, code, fact-based Q&A, evals
0.3–0.5Low creativity, occasional variationSummarization, translation, technical writing
0.7–0.8Balanced — good default for most tasksGeneral chat, content generation
1.0High creativity, more unpredictableBrainstorming, poetry, story generation
Default: Claude's default temperature is 1.0. For structured output tasks (JSON extraction, code generation), always explicitly set temperature to 0 or a low value. 
import anthropic
client = anthropic.Anthropic()

# Deterministic — for code or data extraction
response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=512,
    temperature=0,
    messages=[{"role": "user", "content": "Write a Python function to reverse a string."}]
)

# Creative — for story writing
response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=512,
    temperature=1.0,
    messages=[{"role": "user", "content": "Write the opening line of a mystery novel."}]
)

max_tokens — Capping Output Length

max_tokens is the maximum number of tokens Claude will generate. The response stops at this limit or when Claude naturally ends (whichever comes first). There is no minimum — Claude may stop earlier.

  • Short answers: 128–256
  • Paragraphs: 512–1024
  • Long documents: 2048–8192
  • Maximum: 8192 for most models (check model docs)

stop_sequences — Custom Termination Signals

Stop sequences let you define custom strings that, when generated by Claude, cause output to stop immediately (before the string is included in the response).

# Stop output when Claude writes "---" (useful for structured extraction)
response = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=512,
    stop_sequences=["---", "END"],
    messages=[{"role": "user", "content": "List 3 items. Write --- after the last one."}]
)
# stop_reason will be "stop_sequence" if triggered
print(response.stop_reason)

Streaming — Tokens as They Arrive

By default, the SDK waits for the full response before returning. With streaming, tokens are delivered as they're generated — enabling real-time UX like typewriter effects.

# Streaming with the context manager
with client.messages.stream(
    model="claude-sonnet-4-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain quantum entanglement simply."}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)  # Print each token as it arrives
    print()  # Newline after completion

# Access the final message after streaming
final_message = stream.get_final_message()
print(f"\nTotal tokens: {final_message.usage.input_tokens + final_message.usage.output_tokens}")
When to use streaming: Any user-facing application where responses take more than ~1 second to generate. Streaming dramatically improves perceived performance — users see progress immediately rather than staring at a loading spinner.

Streaming Event Types

The full streaming API exposes events for granular control:

with client.messages.stream(...) as stream:
    for event in stream:
        if event.type == "content_block_start":
            pass  # Block started
        elif event.type == "content_block_delta":
            print(event.delta.text, end="", flush=True)
        elif event.type == "message_stop":
            print("\n[Stream complete]")

Lab: Temperature Comparison Experiment

Run the same creative prompt at three different temperatures and observe how outputs differ.

Open in Colab 
"""
temperature_experiment.py — Compare Claude outputs at different temperatures
"""
import anthropic

client = anthropic.Anthropic()

CREATIVE_PROMPT = "In one sentence, describe the feeling of discovering something unexpected."
CODE_PROMPT = "Write a Python one-liner to flatten a nested list [[1,[2,3]],[4,5]]."

def compare_temperatures(prompt: str, temperatures: list[float], runs: int = 2) -> None:
    """Run the same prompt multiple times at each temperature."""
    print(f"\nPrompt: {prompt}")
    print("=" * 60)

    for temp in temperatures:
        print(f"\n--- Temperature: {temp} ---")
        for i in range(runs):
            response = client.messages.create(
                model="claude-haiku-4-5",
                max_tokens=128,
                temperature=temp,
                messages=[{"role": "user", "content": prompt}]
            )
            print(f"Run {i+1}: {response.content[0].text.strip()}")


# Test 1: Creative prompt — expect variation at high temp
print("\n### CREATIVE PROMPT ###")
compare_temperatures(CREATIVE_PROMPT, [0.0, 0.7, 1.0], runs=3)

# Test 2: Code prompt — expect consistency at low temp
print("\n### CODE PROMPT ###")
compare_temperatures(CODE_PROMPT, [0.0, 0.7, 1.0], runs=3)


# --- Streaming demo ---
print("\n\n### STREAMING DEMO ###")
print("Watching tokens arrive in real time:\n")

with client.messages.stream(
    model="claude-haiku-4-5",
    max_tokens=256,
    temperature=0.8,
    messages=[{"role": "user", "content": "Tell me a 3-sentence story about a robot learning to paint."}]
) as stream:
    for text in stream.text_stream:
        print(text, end="", flush=True)
    print()

    msg = stream.get_final_message()
    print(f"\nInput tokens : {msg.usage.input_tokens}")
    print(f"Output tokens: {msg.usage.output_tokens}")
    print(f"Stop reason  : {msg.stop_reason}")


# --- stop_sequences demo ---
print("\n\n### STOP SEQUENCES DEMO ###")
response = client.messages.create(
    model="claude-haiku-4-5",
    max_tokens=256,
    stop_sequences=["DONE"],
    messages=[{"role": "user", "content": "List 3 programming languages, then write DONE."}]
)
print(f"Response: {response.content[0].text}")
print(f"Stop reason: {response.stop_reason}")  # Should be "stop_sequence"
