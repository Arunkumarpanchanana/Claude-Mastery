Multi-Turn Conversations & System Prompts

Build stateful conversations by managing message history yourself — and shape Claude's behavior with a powerful system prompt.

40 min Intermediate Code Lab 5 Quiz Questions

The API Is Stateless

Each call to messages.create() is independent. Claude does not remember previous messages automatically — you must send the entire conversation history with every request. This is a feature, not a bug: it gives you full control over what context Claude sees.

Building the Message History Array

The messages parameter is an ordered list of alternating user/assistant turns:

messages = [
    {"role": "user",      "content": "My name is Alex."},
    {"role": "assistant", "content": "Nice to meet you, Alex! How can I help?"},
    {"role": "user",      "content": "What's my name?"},
]
# Claude will correctly answer "Your name is Alex."
Rules for the messages array:
  • Must start with a user turn
  • Must alternate: user → assistant → user → assistant…
  • The last message must be a user turn
  • No empty content strings allowed

Roles: user vs assistant

user represents human input (or tool results). assistant represents Claude's prior responses. When building a chatbot, append each exchange to the history list before the next API call.

The System Prompt Parameter

The system parameter is a top-level string that sets Claude's persona, constraints, and context for the entire conversation. It is not part of the messages array.

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=1024,
    system="You are a concise technical assistant. Answer in plain text only. No markdown. Keep responses under 3 sentences.",
    messages=[
        {"role": "user", "content": "What is a REST API?"}
    ]
)

System Prompt Best Practices

  • Define the persona — who Claude is in this context
  • Set output constraints — format, length, tone, language
  • Provide domain context — what the app does, who the user is
  • Specify what NOT to do — topics to avoid, off-limits actions

Context Window Management

As conversations grow, the message history gets longer and costs more. Common strategies:

  • Sliding window — keep only the last N turns
  • Summarization — periodically ask Claude to summarize the conversation so far, then replace history with the summary
  • Selective pruning — remove tool-use turns once they're no longer relevant
def trim_history(messages: list, max_turns: int = 10) -> list:
    """Keep only the most recent max_turns exchanges."""
    # Each exchange = 2 messages (user + assistant)
    if len(messages) > max_turns * 2:
        return messages[-(max_turns * 2):]
    return messages

Lab: Build a Multi-Turn Chatbot

A complete interactive chatbot that maintains conversation history and uses a system prompt to shape its persona.

Open in Colab 
"""
chatbot.py — Multi-turn chatbot with system prompt and history trimming
Run: python chatbot.py
"""
import anthropic

client = anthropic.Anthropic()

SYSTEM_PROMPT = """You are Ada, a friendly Python programming tutor.
Your rules:
- Always encourage the learner, even when they make mistakes
- Provide working code examples when asked
- Explain concepts at a beginner level unless the user says otherwise
- If you don't know something, say so honestly
- Keep responses focused and under 200 words unless code is needed
"""

def chat(messages: list, user_input: str) -> tuple[str, list]:
    """
    Send a user message, get Claude's response, and return
    the updated message history.
    """
    messages.append({"role": "user", "content": user_input})

    response = client.messages.create(
        model="claude-haiku-4-5",  # Fast for chat
        max_tokens=1024,
        system=SYSTEM_PROMPT,
        messages=messages
    )

    assistant_reply = response.content[0].text
    messages.append({"role": "assistant", "content": assistant_reply})

    return assistant_reply, messages


def run_chatbot():
    """Interactive CLI chatbot loop."""
    history = []
    print("Ada: Hi! I'm Ada, your Python tutor. What would you like to learn today?")
    print("(Type 'quit' to exit, 'history' to see message count)\n")

    while True:
        user_input = input("You: ").strip()

        if not user_input:
            continue
        if user_input.lower() == "quit":
            print("Ada: Happy coding! Goodbye!")
            break
        if user_input.lower() == "history":
            print(f"[{len(history)} messages in history]")
            continue

        # Trim history if it gets long (optional)
        if len(history) > 20:
            history = history[-20:]
            print("[Context trimmed to last 10 turns]")

        reply, history = chat(history, user_input)
        print(f"\nAda: {reply}\n")


# --- Demo mode (non-interactive, for testing) ---
def demo_conversation():
    """Simulate a 3-turn conversation to show context retention."""
    history = []
    turns = [
        "My name is Jordan and I'm new to Python.",
        "What data type should I use to store a list of items?",
        "Can you show me how to add an item to it?",
    ]

    for turn in turns:
        print(f"User: {turn}")
        reply, history = chat(history, turn)
        print(f"Ada : {reply}\n")
        print(f"[History length: {len(history)} messages]\n")


if __name__ == "__main__":
    import sys
    if "--demo" in sys.argv:
        demo_conversation()
    else:
        run_chatbot()

Run the demo

python chatbot.py --demo

You'll see Ada correctly reference "Jordan" in later turns, demonstrating that context is preserved through the history array.
