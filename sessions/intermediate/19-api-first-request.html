API Keys & Your First API Request

From zero to a working Claude API call in under 10 minutes — keys, SDK install, first response, error handling.

40 min Intermediate Code Lab 5 Quiz Questions

Step 1 — Get Your API Key

Navigate to console.anthropic.com, sign up or log in, and go to API Keys in the left sidebar. Click Create Key, give it a descriptive name (e.g., "local-dev"), and copy it immediately — it won't be shown again.

Security: Never hardcode an API key in source code. Store it as an environment variable. Use a .env file locally (and add it to .gitignore), or use your deployment platform's secrets manager in production.

Set the environment variable in your shell:

# In your terminal (bash/zsh)
export ANTHROPIC_API_KEY="sk-ant-..."

# Or add to ~/.zshrc / ~/.bashrc so it persists
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc

Step 2 — Install the Python SDK

pip install anthropic

# With a virtual environment (recommended)
python -m venv .venv
source .venv/bin/activate
pip install anthropic

Step 3 — Your First messages.create() Call

The core API method is client.messages.create(). It takes three required parameters: model, max_tokens, and messages.

import anthropic

client = anthropic.Anthropic()
# The SDK auto-reads ANTHROPIC_API_KEY from the environment.
# You can also pass it explicitly: anthropic.Anthropic(api_key="sk-ant-...")

response = client.messages.create(
    model="claude-sonnet-4-5",
    max_tokens=1024,
    messages=[
        {"role": "user", "content": "What is the capital of France?"}
    ]
)

print(response.content[0].text)
# Output: The capital of France is Paris.

Step 4 — Understanding the Response Object

The response is a Message object with several key fields:

print(response.id)            # msg_01XFDUDYJgAACzvnptvVoYEL
print(response.type)          # "message"
print(response.role)          # "assistant"
print(response.model)         # "claude-sonnet-4-5"
print(response.stop_reason)   # "end_turn" | "max_tokens" | "stop_sequence" | "tool_use"

# Content is a list — usually one TextBlock for simple responses
print(response.content)       # [TextBlock(text="...", type="text")]
print(response.content[0].text)  # The actual text string

# Token usage
print(response.usage.input_tokens)   # tokens in your prompt
print(response.usage.output_tokens)  # tokens in the response

Step 5 — Error Handling Basics

The SDK raises typed exceptions so you can handle specific cases:

import anthropic

client = anthropic.Anthropic()

try:
    response = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=1024,
        messages=[{"role": "user", "content": "Hello!"}]
    )
    print(response.content[0].text)

except anthropic.AuthenticationError:
    print("Invalid API key — check ANTHROPIC_API_KEY")

except anthropic.RateLimitError:
    print("Rate limit hit — add exponential backoff")

except anthropic.APIConnectionError:
    print("Network error — check your connection")

except anthropic.APIStatusError as e:
    print(f"API error {e.status_code}: {e.message}")

Always Check stop_reason

If stop_reason is "max_tokens", the response was cut off. Increase max_tokens or restructure your request.

if response.stop_reason == "max_tokens":
    print("Warning: response was truncated. Increase max_tokens.")
elif response.stop_reason == "end_turn":
    print("Complete response received.")
max_tokens guidance: Set it generously for the expected output length, but not excessively — you're charged for output tokens generated, not for the max you set. Setting max_tokens=8192 for a one-sentence answer doesn't cost extra; it just caps the maximum.

Lab: Build Your First API Script

This lab walks you through a complete, production-ready first script with proper environment variable handling, error handling, and response inspection.

Open in Colab 
"""
first_api_call.py — Your first Anthropic API script
Run: python first_api_call.py
"""
import os
import anthropic

# Check key is set before making any call
if not os.environ.get("ANTHROPIC_API_KEY"):
    raise EnvironmentError(
        "ANTHROPIC_API_KEY not set.\n"
        "Run: export ANTHROPIC_API_KEY='sk-ant-...'"
    )

client = anthropic.Anthropic()

def ask_claude(question: str, model: str = "claude-haiku-4-5") -> str:
    """Send a single question to Claude and return the text response."""
    response = client.messages.create(
        model=model,
        max_tokens=512,
        messages=[{"role": "user", "content": question}]
    )

    if response.stop_reason == "max_tokens":
        print("[Warning] Response was truncated — consider increasing max_tokens")

    return response.content[0].text


def inspect_response(question: str) -> None:
    """Make an API call and print a detailed inspection of the response."""
    print(f"\nQuestion: {question}")
    print("-" * 50)

    response = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=256,
        messages=[{"role": "user", "content": question}]
    )

    print(f"Response ID  : {response.id}")
    print(f"Model        : {response.model}")
    print(f"Stop reason  : {response.stop_reason}")
    print(f"Input tokens : {response.usage.input_tokens}")
    print(f"Output tokens: {response.usage.output_tokens}")
    print(f"Content type : {response.content[0].type}")
    print(f"\nText:\n{response.content[0].text}")


# --- Run the examples ---
if __name__ == "__main__":
    # Simple call
    answer = ask_claude("Name three programming languages invented before 1990.")
    print("Simple call result:")
    print(answer)

    # Detailed inspection
    inspect_response("What is recursion in programming?")

    # Error handling demo
    try:
        bad_client = anthropic.Anthropic(api_key="invalid-key")
        bad_client.messages.create(
            model="claude-haiku-4-5",
            max_tokens=10,
            messages=[{"role": "user", "content": "test"}]
        )
    except anthropic.AuthenticationError as e:
        print(f"\nCaught expected auth error: {e}")
