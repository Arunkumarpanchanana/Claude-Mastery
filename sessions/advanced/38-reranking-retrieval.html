Reranking & Contextual Retrieval

Dramatically improve RAG accuracy with cross-encoder reranking and Anthropic's contextual retrieval technique that prepends chunk context using Claude.

45 min Advanced Code Lab 5 Quiz Questions

The Retrieval Accuracy Problem

Even with hybrid search, initial retrieval is imprecise. A retriever must search millions of documents in milliseconds — it optimizes for speed over accuracy. This means your top-5 retrieved chunks might rank a moderately relevant chunk above a highly relevant one.

The solution is a two-stage pipeline: retrieve broadly (top-50), then rerank precisely (select top-5). Reranking uses more expensive but accurate models that deeply compare query and document.

Bi-Encoders vs Cross-Encoders

Bi-Encoder (for retrieval)

  • Encodes query and doc independently
  • Produces separate vectors, compared by dot product
  • Very fast — pre-compute doc embeddings
  • Less accurate — no direct query-doc interaction
  • Used for first-stage retrieval at scale

Cross-Encoder (for reranking)

  • Encodes query AND doc together as a pair
  • Full attention across both — sees all interactions
  • Slower — can't pre-compute, must run per query
  • Much more accurate relevance scoring
  • Used on small candidate sets (top-20 to top-50)

Cross-Encoder Reranking with sentence-transformers

from sentence_transformers import CrossEncoder

# Load a cross-encoder trained for relevance scoring
# ms-marco is trained on 500K query-passage relevance pairs
reranker = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')

query = "How does attention mechanism work in transformers?"
candidates = [
    "Attention computes weighted sums of value vectors based on query-key dot products.",
    "Transformers were introduced in 2017 by Vaswani et al.",
    "The self-attention mechanism allows each token to attend to all other tokens in the sequence.",
    "BERT uses bidirectional attention while GPT uses causal attention.",
    "RAG pipelines combine retrieval with generation for knowledge-grounded answers.",
]

# Score all candidates against the query
pairs = [[query, doc] for doc in candidates]
scores = reranker.predict(pairs)

# Rerank
ranked = sorted(zip(candidates, scores), key=lambda x: x[1], reverse=True)
for doc, score in ranked:
    print(f"{score:+.3f} | {doc[:70]}")
Output interpretation: The cross-encoder will score the attention-specific passages highest (~9.0+) and the unrelated RAG passage lowest (~-10). The scores are not probabilities — only the ranking matters.

Cohere Rerank API

For production systems, Cohere's Rerank API is a managed cross-encoder that handles the infrastructure. It supports multilingual reranking and returns relevance scores with just one API call.

import cohere

co = cohere.Client()  # uses COHERE_API_KEY

results = co.rerank(
    model="rerank-english-v3.0",
    query="How does self-attention work?",
    documents=candidates,
    top_n=3,
    return_documents=True
)

for r in results.results:
    print(f"Rank {r.index}: score={r.relevance_score:.4f}")
    print(f"  {r.document.text[:100]}")
    print()

Anthropic's Contextual Retrieval

Contextual Retrieval is a technique Anthropic published that dramatically improves retrieval accuracy by solving the chunk context problem: when a chunk is extracted from a document, it often loses the context that makes it meaningful.

Consider this chunk from a financial report:

"The company's revenue grew 23% year-over-year to $4.2 billion."

Without context, you don't know which company, which year, or which product line. A RAG query about "Apple's 2023 iPhone revenue" would likely miss this chunk.

Contextual Retrieval fixes this by having Claude prepend a short situating sentence to each chunk before embedding it:

"This chunk is from Apple's Q4 2023 earnings report discussing iPhone revenue growth. The company's revenue grew 23% year-over-year to $4.2 billion."

Implementing Contextual Retrieval

import anthropic

client = anthropic.Anthropic()

CONTEXT_PROMPT = """<document>
{full_document}
</document>

Here is a chunk from this document:
<chunk>
{chunk}
</chunk>

Write a short (1-2 sentence) context that situates this chunk within the overall document.
This context will be prepended to the chunk for retrieval purposes.
Respond only with the context — no preamble or explanation."""

def add_context_to_chunk(full_document: str, chunk: str) -> str:
    """Use Claude to prepend situating context to a chunk."""
    response = client.messages.create(
        model="claude-haiku-4-5",  # Use Haiku for cost efficiency at scale
        max_tokens=100,
        messages=[{
            "role": "user",
            "content": CONTEXT_PROMPT.format(
                full_document=full_document[:5000],  # Truncate if needed
                chunk=chunk
            )
        }]
    )
    context = response.content[0].text.strip()
    # Prepend context to original chunk
    return f"{context}\n\n{chunk}"

# Example usage
document = """
Apple Inc. Q4 2023 Earnings Report

iPhone: The company's revenue grew 23% year-over-year to $4.2 billion
from the iPhone product line, driven by strong iPhone 15 Pro demand.

Mac: Mac revenue declined 3% to $1.8 billion amid a challenging PC market.
Services revenue reached a record $21.2 billion, up 16% year-over-year.
"""

chunk = "The company's revenue grew 23% year-over-year to $4.2 billion."
contextualized = add_context_to_chunk(document, chunk)
print(contextualized)
# Output:
# This chunk is from Apple's Q4 2023 earnings report, discussing iPhone revenue performance.
#
# The company's revenue grew 23% year-over-year to $4.2 billion.

Batch Processing with Prompt Caching

Running Claude on every chunk is expensive. Anthropic's recommended approach uses prompt caching to cache the full document in the system prompt, dramatically reducing costs when adding context to many chunks from the same document.

def contextualize_chunks_with_caching(
    full_document: str,
    chunks: list[str]
) -> list[str]:
    """
    Add context to all chunks efficiently using prompt caching.
    The full document is cached after the first chunk — subsequent chunks
    only send the new chunk content.
    """
    contextualized = []

    for i, chunk in enumerate(chunks):
        response = client.messages.create(
            model="claude-haiku-4-5",
            max_tokens=100,
            system=[
                {
                    "type": "text",
                    "text": f"You are a document context assistant. Here is the full document:\n\n{full_document}",
                    "cache_control": {"type": "ephemeral"}  # Cache the document!
                }
            ],
            messages=[{
                "role": "user",
                "content": f"Provide 1-2 sentences of context for this chunk:\n\n{chunk}"
            }]
        )
        context = response.content[0].text.strip()
        contextualized.append(f"{context}\n\n{chunk}")

        if i == 0:
            print(f"First chunk — document sent and cached")
        else:
            print(f"Chunk {i+1} — using cached document")

    return contextualized
Anthropic's results: Contextual retrieval reduced retrieval failures by 49% compared to basic RAG. Combined with reranking, failures dropped by 67%. For production RAG, this is one of the highest-ROI improvements you can make.

When to Rerank

Reranking adds latency (50-200ms) and cost. Use it when:

  • Retrieval precision is critical (medical, legal, financial queries)
  • Your initial retrieval pool is 20+ candidates and top-5 quality matters
  • You're seeing "I don't know" answers from Claude despite relevant docs existing
  • Query complexity is high (multi-part questions, hypotheticals)

Skip reranking when: queries are simple, latency is critical (<100ms), or your corpus is small enough that initial retrieval is already precise.

Lab: Add Contextual Retrieval to a RAG Pipeline

Take a basic RAG pipeline and upgrade it with both contextual chunk enrichment and cross-encoder reranking.

Prerequisites

pip install anthropic sentence-transformers faiss-cpu numpy

Step 1: Baseline RAG (without contextual retrieval)

import anthropic
import numpy as np
import faiss
from sentence_transformers import SentenceTransformer, CrossEncoder

client = anthropic.Anthropic()
embedder = SentenceTransformer('all-MiniLM-L6-v2')
reranker = CrossEncoder('cross-encoder/ms-marco-MiniLM-L-6-v2')

DOCUMENT = """
Anthropic Model Card — Claude claude-opus-4-5

Training Approach:
Claude was trained using Constitutional AI (CAI), a technique where a set of
principles guides the model's behavior during RLHF training. The model learns
to critique and revise its own outputs according to these principles.

Context Window:
Claude claude-opus-4-5 supports up to 200,000 tokens in its context window.
This is equivalent to approximately 150,000 words or about 500 pages of text.

Tool Use:
Claude can use tools via function calling. Tools are defined in the API request
and Claude decides when and how to invoke them based on the user's request.
Results are returned to Claude in tool_result messages.

Safety Features:
Claude refuses requests that could enable mass casualties, CSAM, or cyberattacks.
It is designed to be honest even when honesty is uncomfortable for the user.
The model acknowledges uncertainty rather than confabulating answers.
"""

# Basic chunking
raw_chunks = [p.strip() for p in DOCUMENT.split('\n\n') if len(p.strip()) > 50]
print(f"Raw chunks: {len(raw_chunks)}")
for i, c in enumerate(raw_chunks):
    print(f"\nChunk {i}: {c[:80]}...")

Step 2: Add Contextual Retrieval

CONTEXT_PROMPT = """Document: {document}

Chunk: {chunk}

Write 1-2 sentences situating this chunk within the document. Be specific about what section this comes from and what topic it addresses. Reply with only the context."""

def contextualize(document, chunk):
    r = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=80,
        system=[{
            "type": "text",
            "text": f"You contextualize document chunks. Full document:\n{document}",
            "cache_control": {"type": "ephemeral"}
        }],
        messages=[{"role": "user", "content": f"Contextualize this chunk:\n\n{chunk}"}]
    )
    ctx = r.content[0].text.strip()
    return f"{ctx}\n\n{chunk}"

# Build contextual chunks
print("\nBuilding contextual chunks (uses Claude Haiku with prompt caching)...")
contextual_chunks = [contextualize(DOCUMENT, c) for c in raw_chunks]

print(f"\nContextual chunk example:")
print(contextual_chunks[0][:300])

Step 3: Build Indexes for Both Versions

def build_index(chunks):
    embs = embedder.encode(chunks, normalize_embeddings=True).astype('float32')
    idx = faiss.IndexFlatIP(embs.shape[1])
    idx.add(embs)
    return idx

baseline_index = build_index(raw_chunks)
contextual_index = build_index(contextual_chunks)
print("Both indexes built!")

Step 4: Compare With and Without Reranking

def retrieve(query, index, chunks, top_k=5):
    q = embedder.encode([query], normalize_embeddings=True).astype('float32')
    _, ids = index.search(q, top_k)
    return [chunks[i] for i in ids[0] if i >= 0]

def retrieve_and_rerank(query, index, chunks, top_k_retrieve=10, top_k_final=3):
    # Stage 1: broad retrieval
    candidates = retrieve(query, index, chunks, top_k=top_k_retrieve)
    # Stage 2: rerank
    pairs = [[query, c] for c in candidates]
    scores = reranker.predict(pairs)
    ranked = sorted(zip(candidates, scores), key=lambda x: x[1], reverse=True)
    return [c for c, _ in ranked[:top_k_final]]

query = "What safety features does Claude have?"

print("=== BASELINE (no context, no reranking) ===")
for c in retrieve(query, baseline_index, raw_chunks, top_k=3):
    print(f"• {c[:100]}")

print("\n=== CONTEXTUAL (with context, no reranking) ===")
for c in retrieve(query, contextual_index, contextual_chunks, top_k=3):
    print(f"• {c[:120]}")

print("\n=== CONTEXTUAL + RERANKED (best quality) ===")
for c in retrieve_and_rerank(query, contextual_index, contextual_chunks):
    print(f"• {c[:120]}")

# Final answer
best_chunks = retrieve_and_rerank(query, contextual_index, contextual_chunks)
context = "\n\n---\n\n".join(best_chunks)
answer = client.messages.create(
    model="claude-opus-4-5",
    max_tokens=300,
    system="Answer using only the context provided.",
    messages=[{"role": "user", "content": f"Context:\n{context}\n\nQ: {query}"}]
)
print(f"\nFinal Answer:\n{answer.content[0].text}")
You've implemented a production-grade RAG pipeline! Contextual retrieval + reranking is the gold standard for RAG accuracy. The additional cost of Haiku calls for contextualization is typically offset by fewer incorrect answers requiring user follow-ups.
