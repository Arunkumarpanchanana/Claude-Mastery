MCP Transports — STDIO & StreamableHTTP

Master both MCP transport types: use STDIO for local process tools and StreamableHTTP for remote, stateful, multi-tenant MCP servers.

50 min Advanced Code Lab 5 Quiz Questions

MCP Transport Overview

An MCP transport is the communication channel between the MCP client (Claude Code) and the MCP server. It handles how JSON-RPC messages are framed and delivered. MCP supports two official transports: STDIO (Standard Input/Output) and StreamableHTTP (HTTP with optional Server-Sent Events).

STDIO Transport

  • Client spawns server as a subprocess
  • Messages via stdin/stdout pipes
  • One process per client session
  • Perfect for local dev tools
  • No network required, very low latency
  • Simple — just a Python script

StreamableHTTP Transport

  • Client connects to HTTP server
  • Supports Server-Sent Events for streaming
  • One server, many clients
  • Perfect for shared/remote servers
  • Supports authentication (API keys, OAuth)
  • Stateful sessions via session IDs

STDIO Transport Deep Dive

STDIO is the simplest and most common transport for local tools. The client starts your server as a subprocess and communicates via newline-delimited JSON on stdin/stdout.

The JSON Message Format

# Each message is a single line of JSON on stdout
# Requests from client to server:
{"jsonrpc": "2.0", "id": 1, "method": "tools/call", "params": {"name": "read_file", "arguments": {"path": "test.py"}}}

# Responses from server to client:
{"jsonrpc": "2.0", "id": 1, "result": {"content": [{"type": "text", "text": "...file content..."}]}}

# Notifications (no id — no response expected):
{"jsonrpc": "2.0", "method": "notifications/progress", "params": {"progressToken": "abc", "progress": 5, "total": 10}}

Complete STDIO Server

#!/usr/bin/env python3
# my_stdio_server.py — A complete STDIO MCP server

import asyncio
from mcp.server import Server
from mcp.server.stdio import stdio_server
from mcp.server.models import InitializationOptions
import mcp.types as types

app = Server("my-local-tool")

@app.list_tools()
async def list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="hello",
            description="A simple hello tool",
            inputSchema={
                "type": "object",
                "properties": {
                    "name": {"type": "string", "description": "Name to greet"}
                },
                "required": ["name"]
            }
        )
    ]

@app.call_tool()
async def call_tool(name: str, arguments: dict) -> list[types.TextContent]:
    if name == "hello":
        return [types.TextContent(type="text", text=f"Hello, {arguments['name']}!")]
    raise ValueError(f"Unknown tool: {name}")

async def main():
    async with stdio_server() as (read_stream, write_stream):
        await app.run(
            read_stream,
            write_stream,
            InitializationOptions(
                server_name="my-local-tool",
                server_version="1.0.0",
                capabilities=app.get_capabilities(
                    notification_options=types.NotificationOptions(),
                    experimental_capabilities={}
                )
            )
        )

if __name__ == "__main__":
    asyncio.run(main())

StreamableHTTP Transport Deep Dive

StreamableHTTP runs as a persistent HTTP server. Multiple clients can connect simultaneously. It supports Server-Sent Events (SSE) for streaming responses from server to client.

Why StreamableHTTP?

  • Multi-tenant: One server instance serves your entire team
  • Authentication: Add API keys, OAuth, or JWT validation
  • Shared state: Maintain connection pools, caches, user sessions
  • Remote deployment: Run on a server, accessed by any Claude Code instance
  • Scalability: Deploy behind a load balancer

Complete StreamableHTTP Server

#!/usr/bin/env python3
# my_http_server.py — StreamableHTTP MCP server using FastAPI

import asyncio
import uuid
from fastapi import FastAPI, Request, Header
from fastapi.responses import StreamingResponse
from mcp.server import Server
from mcp.server.streamable_http import StreamableHTTPServerTransport
from mcp.server.models import InitializationOptions
import mcp.types as types

app_server = Server("remote-tool")
fastapi_app = FastAPI()

# Per-session state (each client gets an isolated session)
sessions: dict[str, dict] = {}

@app_server.list_tools()
async def list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="get_session_data",
            description="Returns data specific to this client session",
            inputSchema={
                "type": "object",
                "properties": {},
                "required": []
            }
        ),
        types.Tool(
            name="store_note",
            description="Store a note in this session",
            inputSchema={
                "type": "object",
                "properties": {
                    "note": {"type": "string"}
                },
                "required": ["note"]
            }
        )
    ]

@app_server.call_tool()
async def call_tool(name: str, arguments: dict) -> list[types.TextContent]:
    # Get session ID from context (set by the transport layer)
    session_id = app_server.request_context.session_id if hasattr(app_server.request_context, 'session_id') else "unknown"

    if name == "get_session_data":
        data = sessions.get(session_id, {"notes": [], "request_count": 0})
        return [types.TextContent(type="text", text=str(data))]

    elif name == "store_note":
        if session_id not in sessions:
            sessions[session_id] = {"notes": [], "request_count": 0}
        sessions[session_id]["notes"].append(arguments["note"])
        sessions[session_id]["request_count"] += 1
        return [types.TextContent(type="text", text=f"Note stored. Total notes: {len(sessions[session_id]['notes'])}")]

    raise ValueError(f"Unknown tool: {name}")

@fastapi_app.post("/mcp")
async def handle_mcp_post(request: Request, x_api_key: str = Header(None)):
    """Handle MCP requests via HTTP POST."""
    # Authentication
    if x_api_key != "secret-api-key-123":
        from fastapi.responses import JSONResponse
        return JSONResponse({"error": "Unauthorized"}, status_code=401)

    # Create a new session ID for this client if needed
    session_id = request.headers.get("mcp-session-id") or str(uuid.uuid4())

    transport = StreamableHTTPServerTransport(
        mcp_session_id=session_id,
        is_json_response_enabled=True
    )

    async def run():
        async with transport.connect() as streams:
            await app_server.run(
                streams[0], streams[1],
                InitializationOptions(
                    server_name="remote-tool",
                    server_version="1.0.0",
                    capabilities=app_server.get_capabilities(
                        notification_options=types.NotificationOptions(),
                        experimental_capabilities={}
                    )
                )
            )

    return await transport.handle_request(request, run)

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(fastapi_app, host="0.0.0.0", port=8080)

Choosing the Right Transport

FactorUse STDIOUse StreamableHTTP
DeploymentLocal machineRemote server, cloud
UsersSingle userTeam / multiple users
StatePer-process (ephemeral)Persistent sessions
Auth neededNo (process isolation)Yes (API keys, OAuth)
StreamingN/ASSE for long responses
Setup complexityLowMedium-High

Lab: Convert a STDIO MCP Server to StreamableHTTP

Take a working STDIO MCP server and convert it to StreamableHTTP, adding authentication and session state management.

Step 1: The Original STDIO Server

#!/usr/bin/env python3
# original_stdio_server.py — We'll convert this to HTTP

import asyncio
from mcp.server import Server
from mcp.server.stdio import stdio_server
from mcp.server.models import InitializationOptions
import mcp.types as types

app = Server("notes-tool")
in_memory_notes = []  # Session state

@app.list_tools()
async def list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="add_note",
            description="Add a note to the in-memory note store",
            inputSchema={
                "type": "object",
                "properties": {
                    "content": {"type": "string", "description": "Note content"},
                    "tag": {"type": "string", "description": "Optional tag", "default": "general"}
                },
                "required": ["content"]
            }
        ),
        types.Tool(
            name="list_notes",
            description="List all stored notes",
            inputSchema={
                "type": "object",
                "properties": {
                    "tag": {"type": "string", "description": "Filter by tag (optional)"}
                }
            }
        )
    ]

@app.call_tool()
async def call_tool(name: str, arguments: dict) -> list[types.TextContent]:
    global in_memory_notes

    if name == "add_note":
        note = {
            "content": arguments["content"],
            "tag": arguments.get("tag", "general"),
            "id": len(in_memory_notes) + 1
        }
        in_memory_notes.append(note)
        return [types.TextContent(type="text", text=f"Note #{note['id']} added.")]

    elif name == "list_notes":
        tag_filter = arguments.get("tag")
        notes = in_memory_notes if not tag_filter else [n for n in in_memory_notes if n["tag"] == tag_filter]
        if not notes:
            return [types.TextContent(type="text", text="No notes found.")]
        text = "\n".join([f"#{n['id']} [{n['tag']}]: {n['content']}" for n in notes])
        return [types.TextContent(type="text", text=text)]

    raise ValueError(f"Unknown tool: {name}")

async def main():
    async with stdio_server() as (r, w):
        await app.run(r, w, InitializationOptions(
            server_name="notes-tool", server_version="1.0.0",
            capabilities=app.get_capabilities(
                notification_options=types.NotificationOptions(),
                experimental_capabilities={}
            )
        ))

if __name__ == "__main__":
    asyncio.run(main())

Step 2: The Converted HTTP Server

#!/usr/bin/env python3
# converted_http_server.py — Same functionality, HTTP transport

from fastapi import FastAPI, Request, HTTPException, Header
from fastapi.responses import JSONResponse
import uvicorn
import uuid
import json
import asyncio
from datetime import datetime

fastapi_app = FastAPI(title="Notes MCP Server (HTTP)")

# Per-session note storage (HTTP version is multi-tenant!)
SESSION_NOTES: dict[str, list[dict]] = {}
VALID_API_KEYS = {"my-secret-key-123", "team-key-456"}

def get_or_create_session(session_id: str) -> list[dict]:
    if session_id not in SESSION_NOTES:
        SESSION_NOTES[session_id] = []
    return SESSION_NOTES[session_id]

def handle_tool_call(tool_name: str, arguments: dict, session_id: str) -> dict:
    """Business logic — identical to STDIO version, but session-aware."""
    notes = get_or_create_session(session_id)

    if tool_name == "add_note":
        note = {
            "content": arguments["content"],
            "tag": arguments.get("tag", "general"),
            "id": len(notes) + 1,
            "created_at": datetime.now().isoformat()
        }
        notes.append(note)
        return {"content": [{"type": "text", "text": f"Note #{note['id']} added."}]}

    elif tool_name == "list_notes":
        tag_filter = arguments.get("tag")
        filtered = notes if not tag_filter else [n for n in notes if n["tag"] == tag_filter]
        if not filtered:
            text = "No notes found."
        else:
            text = "\n".join([f"#{n['id']} [{n['tag']}]: {n['content']}" for n in filtered])
        return {"content": [{"type": "text", "text": text}]}

    raise ValueError(f"Unknown tool: {tool_name}")

TOOLS = [
    {
        "name": "add_note",
        "description": "Add a note to your personal note store",
        "inputSchema": {
            "type": "object",
            "properties": {
                "content": {"type": "string"},
                "tag": {"type": "string", "default": "general"}
            },
            "required": ["content"]
        }
    },
    {
        "name": "list_notes",
        "description": "List all your stored notes",
        "inputSchema": {
            "type": "object",
            "properties": {"tag": {"type": "string"}}
        }
    }
]

@fastapi_app.post("/mcp")
async def handle_mcp(request: Request, x_api_key: str = Header(None)):
    # Auth
    if x_api_key not in VALID_API_KEYS:
        raise HTTPException(status_code=401, detail="Invalid API key")

    # Session management
    session_id = request.headers.get("mcp-session-id") or str(uuid.uuid4())

    body = await request.json()
    method = body.get("method")
    request_id = body.get("id")
    params = body.get("params", {})

    # Handle MCP JSON-RPC methods
    if method == "initialize":
        return JSONResponse({
            "jsonrpc": "2.0", "id": request_id,
            "result": {
                "protocolVersion": "2024-11-05",
                "serverInfo": {"name": "notes-tool", "version": "2.0.0"},
                "capabilities": {"tools": {}}
            }
        }, headers={"mcp-session-id": session_id})

    elif method == "tools/list":
        return JSONResponse({
            "jsonrpc": "2.0", "id": request_id,
            "result": {"tools": TOOLS}
        })

    elif method == "tools/call":
        tool_name = params.get("name")
        arguments = params.get("arguments", {})
        try:
            result = handle_tool_call(tool_name, arguments, session_id)
            return JSONResponse({"jsonrpc": "2.0", "id": request_id, "result": result})
        except ValueError as e:
            return JSONResponse({
                "jsonrpc": "2.0", "id": request_id,
                "error": {"code": -32601, "message": str(e)}
            })

    elif method == "notifications/initialized":
        return JSONResponse({"jsonrpc": "2.0", "result": None})

    return JSONResponse({
        "jsonrpc": "2.0", "id": request_id,
        "error": {"code": -32601, "message": f"Method not found: {method}"}
    })

@fastapi_app.get("/health")
async def health():
    return {"status": "ok", "sessions": len(SESSION_NOTES)}

if __name__ == "__main__":
    print("Starting Notes MCP Server on http://localhost:8080")
    print("Configure Claude Code with:")
    print('  "url": "http://localhost:8080/mcp"')
    print('  "headers": {"x-api-key": "my-secret-key-123"}')
    uvicorn.run(fastapi_app, host="0.0.0.0", port=8080)
Key differences in the HTTP version: (1) Multi-tenant — each client gets its own session via mcp-session-id header. (2) Authentication — API key validation on every request. (3) Persistent state — notes survive across multiple tool calls from the same client. (4) Deployable to any HTTP host.
