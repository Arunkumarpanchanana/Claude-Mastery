Agents & Workflows — When to Use Each

Understand the critical distinction between deterministic workflows and autonomous agents, and learn a decision framework for choosing the right architecture.

45 min Advanced Code Lab 5 Quiz Questions

The Fundamental Distinction

The AI industry often uses "agent" as a catch-all term for any LLM-powered system. Anthropic's framework draws a sharper distinction based on who controls the flow of execution:

Workflows

Deterministic. Predictable. Programmer-controlled.

  • You define the exact sequence of LLM calls
  • The LLM fills roles within a fixed structure
  • Outputs are predictable and auditable
  • Easier to debug and test
  • Lower failure surface area

Example: Translate text → Review translation → Format output (always in this order)

Agents

Dynamic. Autonomous. LLM-controlled.

  • LLM decides what to do next at each step
  • Can take variable numbers of steps
  • Handles truly open-ended tasks
  • Higher capability ceiling
  • Higher failure risk — errors can compound

Example: "Research this topic" — agent decides what to search, when to stop, what to write

Anthropic's guidance: "Prefer workflows over agents whenever the task can be clearly defined upfront. Agents are powerful but introduce unpredictability. Reserve them for tasks where flexibility is genuinely necessary."

The 4 Core Workflow Patterns

Anthropic identifies four workflow patterns that cover the vast majority of multi-step LLM use cases. Master these before reaching for agents.

Pattern 1: Prompt Chaining

The output of one LLM call becomes the input of the next. Each step is a focused, simple task. The chain adds up to a complex capability.

# Step 1: Extract key points
# Step 2: Translate those points
# Step 3: Format as a structured report
# Each step gets only what it needs — clean separation of concerns

Pattern 2: Parallelization

Run multiple independent LLM calls simultaneously. Use when subtasks don't depend on each other. Fan-out then fan-in.

# Analyze document: section 1, section 2, section 3 → all in parallel
# Then merge results → 3x faster than sequential

Pattern 3: Routing

Classify the input, then route to a specialized handler. Lets you use different prompts, models, or pipelines per input type.

# Customer message → classify intent → route to:
#   "billing" → billing_handler()
#   "technical" → tech_support_handler()
#   "general" → general_handler()

Pattern 4: Orchestration

One LLM orchestrator breaks work into subtasks and delegates to specialized subprompts or workers. The orchestrator synthesizes results.

# Orchestrator: "Write a competitive analysis"
# → delegates to: market_researcher(), financial_analyst(), trend_spotter()
# → synthesizes final report from all three outputs

When Agents Are Necessary

Agents shine when:

  • The number of steps is not known in advance ("keep searching until you find enough evidence")
  • The task requires branching based on real-world results ("if the API fails, try an alternative")
  • The task is exploratory — you can't define the path upfront
  • You need the LLM to observe, plan, and replan dynamically

Decision Framework

Ask these questions in order:
  1. Can I complete this with a single, well-crafted prompt? → Use a single call.
  2. Are the steps fixed and known upfront? → Use a workflow.
  3. Do the steps always run in a predictable pattern? → Use chaining/parallelization/routing.
  4. Does the LLM need to decide what to do next at runtime? → Use an agent.

Tradeoffs Summary

FactorWorkflowAgent
PredictabilityHighLow
DebuggingEasyHard
CostFixedVariable (can spiral)

Lab: Implement a Document Processing Chaining Workflow

Build a 3-step chaining workflow that processes a document: extract key points → assess quality → generate summary report.

import anthropic
from dataclasses import dataclass

client = anthropic.Anthropic()

DOCUMENT = """
Climate change is causing significant shifts in global weather patterns.
Arctic ice is melting at unprecedented rates — the Arctic Ocean could be
ice-free in summer by 2035. Sea levels are rising 3.6mm per year, threatening
coastal cities including Miami, Jakarta, and Amsterdam. Coral reefs, which
support 25% of marine life, are bleaching at twice the historical rate.

On the positive side, renewable energy adoption is accelerating rapidly.
Solar capacity grew 200% globally between 2018-2023. Wind energy now provides
15% of EU electricity. Electric vehicle sales reached 14 million in 2023,
up from 2 million in 2018. Several countries have committed to net-zero
by 2050, and carbon capture technology is advancing.

Economic impacts are mixed. Climate-related disasters cost $313 billion in 2022.
However, the clean energy sector created 12 million jobs globally in 2023.
Green bonds issued in 2023 totaled $1.4 trillion, showing strong investor interest.
"""

@dataclass
class WorkflowState:
    document: str
    key_points: str = ""
    quality_assessment: str = ""
    final_report: str = ""

def step1_extract_key_points(state: WorkflowState) -> WorkflowState:
    """Step 1: Extract structured key points from the document."""
    print("\n[Step 1] Extracting key points...")
    response = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=400,
        messages=[{
            "role": "user",
            "content": f"""Extract the 5 most important factual points from this document.
Format as a numbered list with one sentence per point.

Document:
{state.document}"""
        }]
    )
    state.key_points = response.content[0].text
    print(f"Extracted {state.key_points.count(chr(10))+1} points")
    return state

def step2_assess_quality(state: WorkflowState) -> WorkflowState:
    """Step 2: Assess the quality and balance of the extracted points."""
    print("\n[Step 2] Assessing quality and balance...")
    response = client.messages.create(
        model="claude-haiku-4-5",
        max_tokens=200,
        messages=[{
            "role": "user",
            "content": f"""Review these extracted points for a document about climate change.
Assess: (a) factual accuracy, (b) balance between positive/negative, (c) any critical gaps.
Be concise — 2-3 sentences.

Points:
{state.key_points}"""
        }]
    )
    state.quality_assessment = response.content[0].text
    print("Quality assessment complete")
    return state

def step3_generate_report(state: WorkflowState) -> WorkflowState:
    """Step 3: Generate a polished executive summary combining all chain outputs."""
    print("\n[Step 3] Generating final report...")
    response = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=500,
        messages=[{
            "role": "user",
            "content": f"""Create a concise executive summary (3 paragraphs) for a business audience.

Key Points Extracted:
{state.key_points}

Quality Notes to Address:
{state.quality_assessment}

The summary should be factual, balanced, and actionable."""
        }]
    )
    state.final_report = response.content[0].text
    print("Report generated!")
    return state

# Run the chaining workflow
state = WorkflowState(document=DOCUMENT)
state = step1_extract_key_points(state)
state = step2_assess_quality(state)
state = step3_generate_report(state)

print("\n" + "="*60)
print("FINAL REPORT")
print("="*60)
print(state.final_report)

print("\n" + "="*60)
print("WORKFLOW TRACE")
print("="*60)
print(f"Step 1 (key points):\n{state.key_points[:200]}...")
print(f"\nStep 2 (quality):\n{state.quality_assessment}")
print(f"\nStep 3 (report): [see above]")
Why this is better than one big prompt: Each step uses a focused, simple prompt — Step 1 just extracts, Step 2 just assesses, Step 3 just writes. Step 2 can catch quality issues before they contaminate the final report. You can swap any step independently without affecting others.
