BM25 Search & Multi-Index RAG

Combine lexical BM25 search with semantic embeddings to build hybrid retrieval that outperforms either approach alone.

45 min Advanced Code Lab 5 Quiz Questions

Why Semantic Search Alone Isn't Enough

Semantic search with embeddings is powerful — it can find "automobile" when you search "car" because the vectors are nearby. But it has a critical weakness: it struggles with exact keyword matches. If a user searches for "HIPAA section 164.312" or a specific error code like "ECONNREFUSED", semantic search may return vague conceptually-similar results instead of the exact document containing that string.

This is where BM25 (Best Match 25) shines. BM25 is a classical information retrieval algorithm that ranks documents by term frequency and inverse document frequency. It excels at exact keyword matching and is the backbone of systems like Elasticsearch and Apache Solr.

Key insight: BM25 wins on precision (find exactly this term); semantic wins on recall (find conceptually related content). Combining them — hybrid search — consistently outperforms either alone in retrieval benchmarks.

BM25 Explained

BM25 scores a document d against query q using:

BM25 formula (simplified): For each query term t in document d, score += IDF(t) * (TF(t,d) * (k1+1)) / (TF(t,d) + k1*(1-b+b*|d|/avgdl))

Where: IDF = inverse document frequency (rare terms score higher), TF = term frequency in document, k1 (typically 1.5) controls TF saturation, b (typically 0.75) controls length normalization, avgdl = average document length.

When BM25 Wins vs When Semantic Wins

BM25 Wins When...

  • Query contains specific keywords, codes, or names
  • Exact phrase matching matters ("HIPAA 164.312")
  • Domain-specific jargon not in embedding training data
  • Short, factual lookups ("Python 3.11 release date")
  • No GPU available — BM25 runs on CPU in milliseconds

Semantic Wins When...

  • Query uses synonyms ("car" vs "automobile")
  • Paraphrase matching needed ("how do I..." vs "steps to...")
  • Multilingual queries on English documents
  • Conceptual or abstract queries ("explain transformation")
  • User query is poorly worded but semantically clear

Hybrid Search Architecture

A hybrid retriever runs both BM25 and semantic search in parallel, then merges the result lists. The merging step is critical — raw scores from BM25 and cosine similarity are not comparable (different scales), so we use Reciprocal Rank Fusion (RRF) instead.

Reciprocal Rank Fusion (RRF)

RRF converts rank positions to scores, then sums them. It's robust, requires no tuning, and handles score incompatibility between retrievers.

def reciprocal_rank_fusion(
    result_lists: list[list[int]],
    k: int = 60
) -> list[tuple[int, float]]:
    """
    Merge multiple ranked result lists using RRF.

    Args:
        result_lists: List of ranked document ID lists (best first)
        k: Constant to prevent high scores for top-1 docs (default 60)

    Returns:
        Merged list of (doc_id, rrf_score) sorted by score descending
    """
    scores = {}
    for result_list in result_lists:
        for rank, doc_id in enumerate(result_list):
            if doc_id not in scores:
                scores[doc_id] = 0.0
            scores[doc_id] += 1.0 / (k + rank + 1)

    return sorted(scores.items(), key=lambda x: x[1], reverse=True)

Multi-Index RAG Architecture

For production systems, you often need to search across multiple indexes simultaneously:

  • Dense index — vector embeddings for semantic search
  • Sparse index — BM25 / inverted index for keyword search
  • Metadata index — structured filters (date range, document type, author)
class MultiIndexRetriever:
    """Hybrid retriever combining BM25 and semantic search via RRF."""

    def __init__(self, chunks: list[str], embedder, faiss_index):
        self.chunks = chunks
        self.embedder = embedder
        self.faiss_index = faiss_index

        # Build BM25 index
        tokenized = [c.lower().split() for c in chunks]
        self.bm25 = BM25Okapi(tokenized)

    def semantic_search(self, query: str, k: int = 10) -> list[int]:
        """Return top-k chunk indices via semantic similarity."""
        q_emb = self.embedder.encode([query], normalize_embeddings=True).astype('float32')
        _, indices = self.faiss_index.search(q_emb, k)
        return [int(i) for i in indices[0] if i >= 0]

    def bm25_search(self, query: str, k: int = 10) -> list[int]:
        """Return top-k chunk indices via BM25."""
        scores = self.bm25.get_scores(query.lower().split())
        ranked = np.argsort(scores)[::-1][:k]
        return [int(i) for i in ranked]

    def hybrid_search(self, query: str, k: int = 5) -> list[dict]:
        """Merge BM25 and semantic results using RRF."""
        semantic_ids = self.semantic_search(query, k=10)
        bm25_ids = self.bm25_search(query, k=10)

        # Fuse rankings
        merged = reciprocal_rank_fusion([semantic_ids, bm25_ids])

        results = []
        for doc_id, score in merged[:k]:
            results.append({
                "chunk": self.chunks[doc_id],
                "rrf_score": score,
                "in_semantic": doc_id in semantic_ids,
                "in_bm25": doc_id in bm25_ids
            })
        return results

import numpy as np
import faiss
from rank_bm25 import BM25Okapi
from sentence_transformers import SentenceTransformer
import anthropic

# ── Sample corpus ──────────────────────────────────────────────────────────────
CHUNKS = [
    "RAG stands for Retrieval Augmented Generation. It combines a retrieval system with a language model.",
    "BM25 is a probabilistic ranking function used in information retrieval systems like Elasticsearch.",
    "Semantic search uses vector embeddings to find conceptually similar documents regardless of exact wording.",
    "Hybrid search combines BM25 lexical retrieval with semantic vector search for better overall recall.",
    "Reciprocal Rank Fusion (RRF) merges result lists from multiple retrieval systems without score normalization.",
    "FAISS is a library for efficient similarity search developed by Facebook AI Research.",
    "ChromaDB is an open-source vector store with built-in persistence and metadata filtering.",
    "Claude claude-opus-4-5 supports a 200,000 token context window, enabling processing of large documents.",
    "Prompt caching in Claude reduces costs by reusing previously processed prompt prefixes.",
    "Constitutional AI is Anthropic's training technique that uses a set of principles to guide model behavior.",
    "ECONNREFUSED error typically means the target server refused the connection on the specified port.",
    "HIPAA section 164.312 covers technical safeguards for electronic protected health information.",
]

# ── Setup ──────────────────────────────────────────────────────────────────────
embedder = SentenceTransformer('all-MiniLM-L6-v2')

# Build semantic index
print("Building semantic index...")
embeddings = embedder.encode(CHUNKS, normalize_embeddings=True).astype('float32')
d = embeddings.shape[1]
faiss_index = faiss.IndexFlatIP(d)
faiss_index.add(embeddings)

# Build BM25 index
tokenized = [c.lower().split() for c in CHUNKS]
bm25 = BM25Okapi(tokenized)

# ── RRF function ───────────────────────────────────────────────────────────────
def rrf(lists, k=60):
    scores = {}
    for lst in lists:
        for rank, doc_id in enumerate(lst):
            scores[doc_id] = scores.get(doc_id, 0.0) + 1.0 / (k + rank + 1)
    return sorted(scores.items(), key=lambda x: x[1], reverse=True)

# ── Individual retrievers ──────────────────────────────────────────────────────
def semantic_search(query, top_k=5):
    q_emb = embedder.encode([query], normalize_embeddings=True).astype('float32')
    distances, indices = faiss_index.search(q_emb, top_k)
    return [int(i) for i in indices[0] if i >= 0]

def bm25_search(query, top_k=5):
    scores = bm25.get_scores(query.lower().split())
    return list(np.argsort(scores)[::-1][:top_k].astype(int))

def hybrid_search(query, top_k=5):
    sem_ids = semantic_search(query, top_k=top_k*2)
    bm_ids = bm25_search(query, top_k=top_k*2)
    merged = rrf([sem_ids, bm_ids])
    return [doc_id for doc_id, _ in merged[:top_k]]

# ── Compare retrievers ─────────────────────────────────────────────────────────
def compare_retrievers(query):
    print(f"\n{'='*60}")
    print(f"Query: {query}")
    print('='*60)

    for name, fn in [("BM25", bm25_search), ("Semantic", semantic_search), ("Hybrid", hybrid_search)]:
        ids = fn(query, top_k=3) if name != "Hybrid" else hybrid_search(query, top_k=3)
        print(f"\n{name}:")
        for i, idx in enumerate(ids, 1):
            print(f"  {i}. {CHUNKS[idx][:80]}...")

# Test with different query types
compare_retrievers("ECONNREFUSED connection error")          # BM25 should win
compare_retrievers("how does retrieval augmented work")     # Semantic should win
compare_retrievers("hybrid search combining multiple indexes")  # Both contribute

# ── Full RAG with hybrid retrieval ─────────────────────────────────────────────
client = anthropic.Anthropic()

def hybrid_rag(question):
    ids = hybrid_search(question, top_k=4)
    context = "\n\n".join([CHUNKS[i] for i in ids])

    response = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=400,
        system="Answer using only the provided context. Be concise.",
        messages=[{
            "role": "user",
            "content": f"Context:\n{context}\n\nQuestion: {question}"
        }]
    )
    return response.content[0].text

print("\n\nHybrid RAG Answer:")
print(hybrid_rag("What are the benefits of combining BM25 with semantic search?"))
