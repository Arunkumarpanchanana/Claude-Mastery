The Anatomy of a Good Subagent

An effective subagent instruction has four components: role, scope, input format, and output format. Vague instructions produce vague outputs that are hard for the orchestrator to use.

Poor Subagent Instruction

Task(
  description="Code reviewer",
  prompt="Look at the code and tell me what you think."
)

Problems: No defined scope, no output format, ambiguous "what you think".

Strong Subagent Instruction

Task(
  description="Security vulnerability scanner",
  prompt="""You are a security-focused code reviewer.

SCOPE: Review ONLY for security vulnerabilities.
Do NOT comment on style, performance, or logic.

INPUT: The Python files in /src/auth/

OUTPUT FORMAT (strict):
CRITICAL: [issue] at [file]:[line]
HIGH: [issue] at [file]:[line]
MEDIUM: [issue] at [file]:[line]
SUMMARY: [N] issues found, [N] critical

If no issues found, output: SUMMARY: Clean - no security issues found."""
)

Scope and Responsibility Boundaries

Overlapping responsibilities between subagents cause duplicated work and conflicting recommendations. Define clear, non-overlapping scopes:

# BAD: Overlapping scopes — both agents will comment on "bad variable names"
subagents = [
    Task("Code quality reviewer", "Review the code quality"),
    Task("Best practices checker", "Check if the code follows best practices")
]

# GOOD: Clear, non-overlapping scopes
subagents = [
    Task("Security scanner",
         "ONLY security vulnerabilities (injection, auth, crypto, data exposure)"),
    Task("Performance analyst",
         "ONLY algorithmic complexity, memory usage, and database query efficiency"),
    Task("Style checker",
         "ONLY naming conventions, docstrings, and PEP 8 compliance"),
]

Subagent Composition Patterns

Pattern 1: Independent Parallel (no dependencies)

# All subagents run simultaneously, results combined at end
results = await asyncio.gather(
    run_subagent("security"),    # Independent
    run_subagent("performance"), # Independent
    run_subagent("style"),       # Independent
)
synthesis = orchestrator_synthesize(results)

Pattern 2: Sequential with Handoff

# Each subagent builds on the previous one's output
outline = await run_subagent("Outliner", "Create a report outline for: " + topic)
draft = await run_subagent("Writer", f"Write the report using this outline:\n{outline}")
final = await run_subagent("Editor", f"Polish and improve this draft:\n{draft}")

Pattern 3: Critic-Reviser Loop

# One subagent creates, another critiques, loop until quality threshold
content = await run_subagent("Creator", task)
for _ in range(3):  # Max 3 revision rounds
    critique = await run_subagent("Critic",
        f"Rate quality 1-10 and list improvements:\n{content}")
    score = extract_score(critique)
    if score >= 8:
        break
    content = await run_subagent("Reviser",
        f"Improve based on:\n{critique}\n\nOriginal:\n{content}")

Testing Subagents

Test each subagent in isolation before assembling the full system. Key things to verify:

def test_subagent(name: str, prompt: str, test_inputs: list[dict]) -> dict:
    """Test a subagent against multiple inputs and check output format."""
    results = {"passed": 0, "failed": 0, "issues": []}

    for test in test_inputs:
        output = run_subagent(name, prompt + "\n\n" + test["input"])

        # Check expected format
        for required_field in test.get("required_fields", []):
            if required_field not in output:
                results["failed"] += 1
                results["issues"].append(
                    f"Missing '{required_field}' in output for input: {test['input'][:50]}"
                )
                continue

        # Check expected content
        if "expected_contains" in test:
            for expected in test["expected_contains"]:
                if expected.lower() not in output.lower():
                    results["failed"] += 1
                    results["issues"].append(f"Expected '{expected}' in output")
                    continue

        results["passed"] += 1

    return results

# Example test
test_results = test_subagent(
    name="Security Scanner",
    prompt="Review code for security issues. Format: CRITICAL/HIGH/MEDIUM: [issue] at [file]:[line]",
    test_inputs=[
        {
            "input": "query = f\"SELECT * FROM users WHERE id={user_id}\"",
            "required_fields": ["CRITICAL"],
            "expected_contains": ["SQL", "injection"]
        },
        {
            "input": "x = 1 + 1",
            "expected_contains": ["SUMMARY: Clean"]
        }
    ]
)
print(test_results)

Common Pitfalls

Pitfall 1: Context overflow — Giving subagents too much context causes them to lose focus. Each subagent should receive only what it needs for its specific task.
Pitfall 2: Unstructured output — If a subagent returns prose instead of structured data, the orchestrator can't reliably parse it. Always specify exact output format.
Pitfall 3: Scope creep — A security subagent that also "helpfully" comments on code style dilutes focus and creates overlapping work. Enforce strict scope in the prompt.
Pitfall 4: No error handling — A subagent that encounters an error might return empty output or an error message. The orchestrator must handle these gracefully rather than passing empty strings to synthesis.

Lab: Multi-Subagent Code Review System

Design and test a complete multi-subagent code review system with clear scope boundaries, structured outputs, and robust error handling.

import anthropic
import json
import re
from concurrent.futures import ThreadPoolExecutor, as_completed
from dataclasses import dataclass, field

client = anthropic.Anthropic()

@dataclass
class ReviewIssue:
    severity: str  # CRITICAL, HIGH, MEDIUM, LOW
    description: str
    location: str

@dataclass
class SubagentResult:
    role: str
    issues: list[ReviewIssue] = field(default_factory=list)
    summary: str = ""
    error: str = ""

    @property
    def success(self):
        return not self.error

# ── Subagent definitions with strict scopes and output formats ─────────────────

SUBAGENT_CONFIGS = {
    "security": {
        "system": """You are a security vulnerability specialist.
SCOPE: ONLY security issues — SQL injection, XSS, CSRF, insecure deserialization,
hardcoded secrets, weak cryptography, authentication bypass, privilege escalation.
DO NOT comment on performance, style, or logic errors.""",
        "output_format": """Report ONLY security issues in this format:
[CRITICAL|HIGH|MEDIUM|LOW]:  at 

End with:
SUMMARY:  security issues found ( critical,  high,  medium,  low)

If no security issues: SUMMARY: Clean - no security issues found"""
    },

    "performance": {
        "system": """You are a performance optimization specialist.
SCOPE: ONLY performance issues — O(n²) algorithms, N+1 database queries,
missing indexes, blocking I/O in async context, large memory allocations,
unnecessary computation inside loops.
DO NOT comment on security, style, or correctness.""",
        "output_format": """Report ONLY performance issues in this format:
[HIGH|MEDIUM|LOW]:  at  (estimated impact: )

End with:
SUMMARY:  performance issues found"""
    },

    "maintainability": {
        "system": """You are a code maintainability specialist.
SCOPE: ONLY maintainability issues — missing docstrings on public functions,
unclear variable names (single letters where descriptive names are appropriate),
functions longer than 50 lines, deep nesting (>4 levels), magic numbers.
DO NOT comment on security or performance.""",
        "output_format": """Report ONLY maintainability issues in this format:
[HIGH|MEDIUM|LOW]:  at 

End with:
SUMMARY:  maintainability issues found"""
    }
}

def run_specialized_review(role: str, code: str) -> SubagentResult:
    """Run a specialized subagent review."""
    config = SUBAGENT_CONFIGS[role]
    try:
        response = client.messages.create(
            model="claude-haiku-4-5",
            max_tokens=600,
            system=config["system"],
            messages=[{
                "role": "user",
                "content": f"{config['output_format']}\n\nCode to review:\n```python\n{code}\n```"
            }]
        )
        output = response.content[0].text

        # Parse structured output
        issues = []
        for line in output.split('\n'):
            match = re.match(r'\[(CRITICAL|HIGH|MEDIUM|LOW)\]: (.+?) at (.+?)$', line.strip())
            if match:
                issues.append(ReviewIssue(
                    severity=match.group(1),
                    description=match.group(2),
                    location=match.group(3)
                ))

        summary_match = re.search(r'SUMMARY: (.+?)$', output, re.MULTILINE)
        summary = summary_match.group(1) if summary_match else "Summary not found"

        return SubagentResult(role=role, issues=issues, summary=summary)

    except Exception as e:
        return SubagentResult(role=role, error=str(e))

def orchestrate_full_review(code: str) -> str:
    """Orchestrate all three review subagents and synthesize results."""
    print("Spawning 3 specialized review subagents in parallel...\n")

    # Parallel fan-out
    with ThreadPoolExecutor(max_workers=3) as executor:
        futures = {
            executor.submit(run_specialized_review, role, code): role
            for role in SUBAGENT_CONFIGS
        }
        results = {}
        for future in as_completed(futures):
            result = future.result()
            results[result.role] = result
            if result.success:
                print(f"[{result.role.upper()}] Done: {result.summary}")
            else:
                print(f"[{result.role.upper()}] ERROR: {result.error}")

    # Count issues by severity
    all_issues = []
    for r in results.values():
        all_issues.extend(r.issues)

    criticals = [i for i in all_issues if i.severity == "CRITICAL"]
    highs = [i for i in all_issues if i.severity == "HIGH"]

    # Orchestrator synthesizes
    issues_text = "\n".join([
        f"[{r.role.upper()}] {i.severity}: {i.description} at {i.location}"
        for r in results.values() if r.success
        for i in r.issues
    ])

    synthesis = client.messages.create(
        model="claude-opus-4-5",
        max_tokens=500,
        system="You are a senior engineering lead synthesizing a code review.",
        messages=[{
            "role": "user",
            "content": f"""Synthesize these specialist reviews into an actionable report.
Prioritize by impact. Be direct and constructive.

All issues found:
{issues_text if issues_text else "No issues found by any reviewer."}

Write: (1) Immediate blockers, (2) Should fix soon, (3) Nice to have"""
        }]
    )

    report = f"""
CODE REVIEW REPORT
==================
Total Issues: {len(all_issues)} | Critical: {len(criticals)} | High: {len(highs)}

SPECIALIST SUMMARIES:
- Security: {results.get('security', SubagentResult('security', error='failed')).summary}
- Performance: {results.get('performance', SubagentResult('performance', error='failed')).summary}
- Maintainability: {results.get('maintainability', SubagentResult('maintainability', error='failed')).summary}

SYNTHESIZED RECOMMENDATIONS:
{synthesis.content[0].text}
"""
    return report
