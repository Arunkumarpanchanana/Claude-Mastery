The Full Anatomy of a Prompt

We introduced prompt basics in Session 2. Now let's build a complete mental model. A fully-formed prompt can have up to six components — not every prompt needs all six, but knowing them gives you a toolkit to draw from.

1

Role (optional but powerful)

"You are a [role]..." — Sets Claude's perspective, expertise, and communication style. Use when you want a specific angle or domain emphasis.

Example: "You are an experienced UX writer who specializes in fintech apps..."

2

Context (often critical)

Background information Claude needs: who you are, what project this is for, what audience will see the output, what assumptions apply.

Example: "...I'm working on a mobile banking app for first-time investors aged 25-35. The app needs to feel approachable, not intimidating."

3

Task (always required)

The core request — what you want Claude to do. Start with a verb. Be specific about what "done" looks like.

Example: "...Write 5 micro-copy variants for the onboarding screen that explains compound interest."

4

Format (often underspecified)

How the output should be structured: length, headings, bullets, tables, code blocks, numbered lists. If you don't specify, Claude guesses — and often guesses wrong for your needs.

Example: "...Format: each variant on its own line, labeled Variant 1-5. Max 25 words each."

5

Constraints (reduces guessing)

What Claude should avoid, what assumptions it shouldn't make, what's off-limits. Constraints sharpen the output space dramatically.

Example: "...Avoid financial jargon. Don't use the phrase 'compound interest' itself in the copy. No exclamation marks."

6

Examples (the secret weapon)

One or two examples of what good output looks like. This is the most powerful calibration tool available. "Few-shot prompting" — providing examples — dramatically improves output quality.

Example: "...Here's the style I'm going for: 'Your money works while you sleep — here's how.' (short, clear, benefit-first)"

Few-Shot Prompting: Show, Don't Just Tell

One example in a prompt is worth a hundred adjectives. When you tell Claude "write in a warm, conversational tone," you get Claude's interpretation of warm and conversational. When you show Claude an example, it calibrates to your specific definition.

Zero-shot (no examples)

Write product descriptions in a casual, friendly tone for our sustainable clothing brand.

Claude guesses at "casual and friendly" — may be off from your specific brand voice.

Few-shot (with examples)

Write product descriptions for our sustainable clothing brand. Here are two examples of our style:
"These aren't just jeans — they're the last pair you'll ever need to buy. Seriously."
"Made from recycled ocean plastic. Feels like cotton. Saves a fish."
Now write one for our new hemp t-shirt collection.

Claude now has a precise calibration target — it matches your specific voice, not a generic "casual."

Few-shot tips:

  • 1-3 examples is usually enough. Too many examples can confuse the calibration.
  • Choose examples that represent the range of what you want, not just one extreme.
  • Bad examples can backfire — make sure your examples are actually good models.
  • For formatting examples, show the exact format structure you want reproduced.

Prompt Iteration: The Real Skill

Even well-crafted prompts often need iteration. The goal of a first prompt is to get something useful to work with, not to get the final output. Here's a structured iteration approach:

First pass: get the shape

Your initial prompt gets the rough structure and approach right. Don't worry about perfection — get something on paper.

Second pass: fix specifics

Identify what's wrong and add specifics: "The third paragraph is too formal. Make it sound more like a conversation." Target your feedback.

Third pass: polish and variants

"This is close — give me 3 variations of the opening sentence." Or "Make the whole thing 20% shorter." Refinement, not reconstruction.

The iteration mindset: Your first prompt is a hypothesis. Claude's response is data. Your next prompt is a revised hypothesis based on that data. Treat it like a dialogue, not a command, and you'll converge on excellent outputs much faster.

Lab: Build a Prompt Library

Create 3 fully-formed prompts for real tasks in your life, using the complete anatomy. Then test and iterate them.

1

Identify 3 recurring tasks

Think of 3 tasks you do repeatedly that Claude could help with. Examples:

  • Writing status update emails to your manager
  • Summarizing long articles or documents
  • Brainstorming ideas for presentations or projects
  • Drafting professional messages for difficult situations
  • Creating study notes or flashcards from reading material

Write them down. These will become your personal prompt templates.

2

Build each prompt using the 6-component anatomy

For each task, write a full prompt template using placeholders for the variable parts. Example structure:

Role: You are [X].
Context: [Background about me and this task].
Task: [Specific action verb + what you want].
Format: [Length, structure, style].
Constraints: [What to avoid].
Example: [If applicable, one example of the output style].

The [brackets] become the things you fill in each time you use it.

3

Test each prompt with real content

Fill in a real instance of each template and test it with Claude. For each:

  • Rate the first output 1-10
  • Write one follow-up prompt that improves it
  • Rate the second output 1-10

Most prompts improve significantly with one targeted iteration. Note what specific change caused the improvement.

4

Add few-shot examples to your best prompt

Take your highest-performing prompt template and add 1-2 examples of ideal output. Test whether adding examples improves quality further.

This is especially powerful for creative tasks, where "good" is hard to define in words but easy to demonstrate with examples.

5

Build your prompt library document

Create a simple document (notes app, Notion, Google Docs) with your 3 refined prompt templates. Give each a descriptive name and note when to use it.

Ask Claude to help you create it:

Help me create a personal prompt library document. Here are the 3 prompts I've developed [paste them]. Format it as a clean reference document with a name, use case, and the template for each.

This document grows over time and becomes one of your most valuable AI productivity assets.
