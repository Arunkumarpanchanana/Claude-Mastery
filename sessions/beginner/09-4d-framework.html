The 4D AI Fluency Framework

Learn the complete mental model — Delegation, Description, Discernment, Diligence — that turns casual AI users into effective AI practitioners.

35 min Beginner Framework Mapping Lab 5 Quiz Questions

Why You Need a Framework

AI fluency isn't just about knowing how to write good prompts. It's a broader set of competencies: knowing when to use AI, how to communicate with it, how to evaluate what it gives you, and how to use it responsibly. The 4D framework gives these competencies names and a structure, making them easier to learn and practice deliberately.

The four Ds are:

Delegation

Deciding what to hand to Claude and what to keep human. Knowing when AI is the right tool and how to break tasks down for it.

Description

Writing prompts that actually get what you need. The art and science of communicating intent clearly to an AI.

Discernment

Critically evaluating AI outputs. Knowing what to trust, what to verify, and what to reject.

Diligence

Using AI responsibly — protecting privacy, maintaining human oversight, attributing work appropriately.

The 4D Loop in Practice

The four Ds don't happen in sequence — they form a loop that repeats with every AI task. Understanding the loop helps you know where you are in any given interaction and what skill you're exercising.

D1

Delegation — Should I use AI for this?

Before opening Claude, ask: Is this a task where AI adds real value? What's my role and what's Claude's role in completing this? Is there anything about this task that requires human judgment, empathy, or accountability that shouldn't be delegated?

Example: Writing a first draft of a report → delegate. Making a final decision about laying off an employee → human judgment required.

D2

Description — How do I ask for this?

Once you've decided to use Claude, craft the request. What context does Claude need? What format do you want? What constraints apply? This is where prompt quality matters enormously.

Example: Instead of "write a report summary," say: "Summarize this 20-page report in 3 paragraphs for a CFO audience who cares about financial risk. Avoid jargon."

D3

Discernment — Is this output good?

Evaluate what Claude gives you. Is it accurate? Does it actually address what you needed? Are there factual claims that need verification? Is there something missing? This is the critical evaluation step.

Example: Claude's code looks right — but did you read it? Does it handle edge cases? Did you run it? Does it have security issues?

D4

Diligence — Am I using this responsibly?

Before using the output: Are you sharing sensitive data you shouldn't? Are you attributing AI assistance where appropriate? Are you maintaining the oversight and accountability that this work requires?

Example: You used Claude to draft a legal document — did you have a lawyer review it before sending? That's diligence.

Real-World Examples: The 4D Loop in Action

Example 1: Writing a performance review for a team member

  • Delegation: Use Claude to help structure and word the review, but you make all the judgments about performance. Don't delegate the evaluation itself.
  • Description: "Help me write a performance review for [name]. Their achievements this year: [list]. Areas for growth: [list]. Tone: constructive and specific. Avoid generic phrases."
  • Discernment: Read carefully — does it misrepresent anything? Does it inadvertently say something you don't mean?
  • Diligence: Don't include private HR data about salary or previous disciplinary actions in the prompt.

Example 2: Researching a competitor

  • Delegation: Use Claude for structuring the analysis framework and synthesizing information you provide, but gather current data yourself (Claude's knowledge is dated).
  • Description: "Analyze this competitor based on the information I've provided. Use a SWOT framework. Focus on go-to-market strategy."
  • Discernment: Verify any facts Claude asserts independently. Check the analysis makes sense given what you know.
  • Diligence: Don't paste confidential company data or trade secrets into the prompt.
The meta-skill: AI fluency is really about maintaining your judgment while leveraging AI's capabilities. The 4D framework keeps you in the driver's seat. You delegate, describe, discern, and apply diligence — Claude executes. The human-in-the-loop isn't a bottleneck; it's the feature.

Lab: Mapping Your Work to the 4D Framework

Apply the 4D framework to tasks from your own life or work. This helps you internalize it as a practical mental model, not just a theory.

1

List 5 tasks from your week

Think about your last week of work (or study). List 5 tasks you completed or need to complete. Examples: writing emails, doing research, analyzing data, drafting documents, planning projects.

For each task, answer: Is this something Claude could help with? What's the value-add?

2

Apply the Delegation filter

For each of your 5 tasks, ask:

  • Which parts require human judgment, relationships, or accountability?
  • Which parts are execution that Claude could accelerate?
  • Are there any tasks on the list that shouldn't involve Claude at all?

Ask Claude to help you analyze your own task list:

Here are 5 tasks from my week: [list them]. For each, tell me what parts would benefit from AI assistance and what parts should remain human-driven.
3

Write a Description for one task

Pick the task from your list most suited for Claude. Write a full Description prompt using everything you've learned so far:

  • Context (who you are, what this is for)
  • Clear task statement
  • Format instructions
  • Constraints or things to avoid
  • Tone instructions

Run it and note the quality difference from a vague prompt.

4

Apply Discernment to the output

After Claude responds, evaluate critically:

  • What did Claude get right?
  • What's missing or wrong?
  • What specific claims, if any, need verification?
  • Rate the output: 1-10 for accuracy, 1-10 for usefulness

Based on your discernment, write a follow-up prompt to improve the output.

5

Diligence check

Review your interaction through the Diligence lens:

  • Did you share any data in the prompt that you shouldn't have (names of clients, confidential numbers, private information)?
  • If you used the output for a real deliverable, did you review it thoroughly enough?
  • If you're sharing this work with others, is it clear what role AI played?

Write a brief Diligence policy for how you'll use Claude in your specific work context.
